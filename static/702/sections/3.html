3. Factoring

We may sometimes assume rings are integral domains and elements are nonzero in this chapter.

3.1. Irreducibility and primality

Definition 14. Suppose 𝑅 is an integral domain.
  1. 𝑎 divides 𝑏 if there exists 𝑞 such that 𝑏=𝑞𝑎.
  2. 𝑎 and 𝑏 are associatives if 𝑎|𝑏 and 𝑏|𝑎. This is equivalent to saying 𝑎=𝑏𝑢 for some unit 𝑢∈𝑅.
  3. A proper factorization of 𝑎 is 𝑎=𝑏𝑐 where 𝑏 and 𝑐 are not units.
  4. 𝑎 is irreducible if it is not a unit and has no proper divisors.
  5. 𝑝∈𝑅 is a prime element if 𝑝 is not a unit, and 𝑝|𝑎𝑏 implies 𝑝|𝑎 or 𝑝|𝑏.

Remark. in ℤ every nonzero prime ideal is maximal, so for any prime number 𝑝, the quotient ℤ/𝑝ℤ is a field.

Warning: irreducibility and primality are not the same thing in general! For example, 3 is irreducible but not prime in ℤ[−5]. In particular, 3|(1+−5(1−−5))=6 but does not divide either 1±−5. Thus 3 is not prime.

Lemma 10.
  1. 𝑎|𝑏 iff (𝑏)⊂(𝑎)
  2. 𝑎 is irreducible if and only if there is not proper prinpical ideal (𝑐) with (𝑎)⊊(𝑐).
  3. Suppose 𝑅 is a PID. If 𝑞∈𝑅 is irreducible, then (𝑞) is maximal.
Proof
(1) and (2) follow from the definitions. (3) is implied by (2).

□

For example, 2 is irreducible in ℤ[𝑥] but is not maximal since (2)⊂(2,𝑥).

Definition 15. Let 𝑅 be an integral domain. 𝑑 is the gcd of 𝑎,𝑏∈𝑅 if
  • 𝑑 divides both 𝑎 and 𝑏
  • If 𝑒∈𝑅 divides both 𝑎∧𝑏, then 𝑒∣𝑑
Say 𝑎,𝑏 are relatively prime if gcd(𝑎,𝑏)=1.

Remark:

  1. The gcd may not exist. For example, consider 𝑅=𝑍[−5] and 𝑎=6,𝑏=2(1−−5). Both 2 and 1−−5 are common divisors.
  2. If 𝑅 is a PID then the gcd always exists, since (𝑎,𝑏)=(𝑑)for some 𝑑.
Lemma 11. Let 𝑅 be a PID. Let 𝑎,𝑏∈𝑅 with both nonzero. Let (𝑑)=(𝑎,𝑏). Then
  1. 𝑅𝑑=𝑅𝑎+𝑅𝑏
  2. 𝑑|𝑎 and 𝑑|𝑏.
  3. If 𝑒∈𝑅 divides both 𝑎 and 𝑏, it also divides 𝑑
  4. 𝑑=𝑟𝑎+𝑠𝑏 for some 𝑟,𝑠∈𝑅.
Proof
(3): Suppose 𝑎=𝑥𝑒,𝑏=𝑦𝑒. (4) implies that 𝑒 divides 𝑑.

□

Proposition 13. Let 𝑅 be a PID, and 𝑎,𝑏∈𝑅.
  1. If 𝑎,𝑏 are relatively prime, 1=𝑟𝑎+𝑠𝑏 for some 𝑟,𝑠∈𝑅.
  2. Maximal ideals of 𝑅 are the principal ideals generated by irreducible elements.
  3. An element in 𝑅 is irreducible if and only if it is prime.
Proof
  1. Follows from last lemma.

  2. Suppose 𝑝 is irreducible and suppose (𝑝)⊂(𝑑). Then by irreducibility we must have 𝑝=𝑢𝑑 or 𝑑=1. We either have (𝑑)=(𝑝) or (𝑑)=𝑅.

    Suppose 𝑀=(𝑝) is maximal and 𝑝 is not irreducible. Then 𝑝=𝑎𝑏 for some non-units 𝑎,𝑏, so (𝑎) is strictly larger than (𝑝). We must have (𝑎)=(𝑝) or (𝑎)=𝑅. The first implies 𝑏 is a unit. and the latter implies 𝑎 is a unit, yielding a contradiction.

  3. Forward: Suppose 𝑝∈𝑅 is prime. Suppose 𝑝 is not irreducible, so we can write 𝑝=𝑎𝑏 for non-units 𝑎,𝑏∈𝑅. By primality, WLOG suppose 𝑝|𝑎. We can write 𝑎=𝑝𝑐, yielding 𝑝=(𝑝𝑐)𝑏=𝑝(𝑐𝑏). Using the cancellation rule for integral domains, we have 1=𝑐𝑏, implying 𝑏 is a unit and yielding a contradiction. Thus 𝑝 must be irreducible.

    Backward: Suppose 𝑝 is irreducible and divides 𝑎𝑏 but not 𝑎. Then 𝑎𝑏∈(𝑝). By (2), we have (𝑝) is maximal. Thus (𝑝,𝑎) must be the entire ring, i.e. 1=𝑎𝑥+𝑝𝑦 for suitable choices of 𝑥,𝑦∈𝑅. Multiplying both sides by 𝑏 yields 𝑏=𝑎𝑏𝑥+𝑝𝑏𝑦. The RHS is divisible by 𝑝, so 𝑏 must be as well.

□

For integral domains we only have one direction guaranteed:

Proposition 14. Let 𝑅 be an integral domain.
  1. A prime element of 𝑅 is irreducible.
Proof
Follow proof of (3) forward. It only requires 𝑅 is a PID.

□

3.2. Euclidean Domains and Unique Factorization Domains

So far the notions of rings we have discussed include

  • integral domain
  • principal ideal domian

We will add two more to the list: Euclidean domain and unique factorization domain

Definition 16. A Euclidean domain is an integral domain 𝑅 with a size function 𝜎:𝑅→ℝ≥0 such that the division algorithm is possible, i.e. for any 𝑎,𝑏∈𝑅, 𝑎≠0, there exist 𝑞,𝑟, not necessarily unique, such that 𝑏=𝑎𝑞+𝑟 with 𝑟=0 or 𝜎(𝑟)<𝜎(𝑎).

Note that 𝜎 under this definition need not be multiplicative. Examples: (ℤ,|𝑥|), (ℤ[𝑖],|𝑥|), (𝐹[𝑥],deg).

Example 3. Prove that ℤ[𝑖] and ℤ[−2] are Euclidean domains, but that ℤ[−5] may not be.

Proof

Define the size function as 𝜎(𝑎+𝑏𝑑)=𝑎2−𝑑𝑏2. Now consider

𝑧1𝑧2=𝑎+𝑏𝑖𝑐+𝑑𝑖=𝑎𝑐−𝑏𝑑𝑐2+𝑑2+𝑖𝑎𝑑+𝑏𝑐𝑐2+𝑑2≡𝑥+𝑖𝑦. (28)
Let 𝑞=⌊𝑥⌉+𝑖⌊𝑦⌉ where ⌊…⌉ denotes round. We have 𝜎(𝑟)=𝜎(𝑧1−𝑞𝑧2)≤𝜎(12𝑧2+12𝑖𝑧2)=12(𝑐−𝑑)2+(𝑐+𝑑)2=𝑐2+𝑑22<|𝑧2|. Thus we have a found a size function that works.

□

The same size function for ℤ[−2] works, but not for ℤ[−5], since we have 1+5>2 (draw the lattice and consider dividing (1+5) by 2). In particular, the step that breaks is the inequality 𝜎(12𝑧2+12𝛿𝑧2)≰|𝑧2| when 𝛿=−5. (I spent a lot of time thinking about this)

You might ask why we can’t try another size function that may work, for example 𝜎(𝑎+𝑏𝑑)=𝑎2+𝑏2. But we should always be able to find a counterexample; in this case, for example consider the lattice formed by the 𝑏=1+5−5.

Later we will prove that ℤ[−5] is not a PID so it cannot be a ED, by the following proposition. Another way is to show that ℤ[−5] is not a UFD since 6=2⋅3=(1+−5)(1−−5), and thus it cannot be a PID nor ED.

The following fact allows us to eliminate candidates for E.D.s.

Proposition 15. Suppose 𝑅 is a Euclidean domain. Then 𝑅 is a principal ideal domain.
Proof
Let 𝑅 be an ED, and let 𝐴∈𝑅 be an ideal. Take a minimal element 𝛼∈𝐴 with respect to the size function. Then (𝛼)⊂𝐴. It suffices to show that 𝐴⊂(𝛼). This follows from divison: 𝑏=𝑞𝛼+𝑟 implies 𝑟∈𝐴, so we must have 𝑟=0, otherwise minimality of 𝛼 is contradicted.

□

Definition 17. An integral domain is a unique factorization domain (UFD) if
  1. Factorization terminates, i.e. any element 𝑎∈𝑅 can be factorized into a product of irreducibles.
  2. The factorization is unique in the sense that 𝑎=𝑝1…𝑝𝑛=𝑞1…𝑝𝑚 then 𝑛=𝑚 and 𝑝𝑖 and 𝑞𝑖 are associatives (up to reordering and multiplication by units if necessary.)

Examples

  • In ℤ[𝑖], 5=(2+𝑖)(2−𝑖)=−(2𝑖−1)(2𝑖+1). 2+𝑖 and (2𝑖−1) are associatives, and (2−𝑖) and (2𝑖+1) are associatives
  • UFDs include ℤ and 𝐹[𝑥] and ℤ[𝑖] (not easy to see) and ℤ[𝑥] (not easy to see).
Lemma 12. Let 𝑅 be an integral domain. The following are equivalent:
  1. Factorization terminates in 𝑅.

  2. There is no infinite series of strictly increasing proper principal ideals:

    (𝑎1)⊊(𝑎2)⊊(𝑎3)⊊… (29)
Proof
Suppose there exists 𝑎∈𝑅 whose factorization does not terminate. Then we get an infinite series of factors 𝑎4|𝑎3|𝑎2|𝑎1|𝑎, implying (𝑎)⊊(𝑎1)⊊(𝑎2)⊊(𝑎3)⊊ Suppose we have an infinite series. We can use it to construct a factorization that does not terminate.

□

Proposition 16. 𝑅 is a PID implies 𝑅 is a UFD.
Proof

Let 𝑅 be a PID. By the previous lemma, it suffices to show there are no infinite series of strictly increasing propering principal ideals.

Suppose there is such a series. Let 𝐽=(𝑏) be the union. It is generated by one element is 𝑅 is a PID. Then there exists (𝑎𝑛) s.t. 𝑏∈𝑎𝑛. Then (𝑎𝑛)=(𝑎𝑛+1)=…, yielding a contradiction.

Now we prove uniqueness. Let 𝑎=𝑝1…𝑝𝑛=𝑞1…𝑞𝑚 for irreducibles {𝑝𝑖} and {𝑞𝑖}. 𝑝1 is prime, meaning it divides one of 𝑞1,…,𝑞𝑚. Thus 𝑝1 and 𝑞1 are associatives. Use the cancellation law, and repeat the process to conclude 𝑛=𝑚.

□

Summary: ED implies PID implies UFD.

Examples

  • ℤ[−5] is not a UFD, since 6=2⋅3=(1+5𝑖)(1−5𝑖). We can show that these four numbers are irreducible by considering the multiplicative norm function 𝑁(𝑎+𝑏−5)=𝑎2+5𝑏2. In particular, no elements of norm 2 or 3 exist in ℤ[−5]. We can to norms to find the units and argue that 2 is not associates with either 1±−5
  • ℤ[𝑖] is a UFD since its a PID.
  • ℤ[𝑥] is not a PID but it is a UFD. We will prove this in the next section.

In Lemma 12, we showed that in a PID, primeness and irreducibility coincide. This occurs in a UFD as well for different reasons.

Proposition 17. In a UFD, primeness and irreducibility coincide.
Proof
For integral domains we have already shown that primality implies irreducibility. It suffices to show that irreducibility implies primality by above. Suppose 𝑥|𝑎𝑏 and 𝑥 is irreducible. By the UFD property, 𝑥 must appear in the factorizations of 𝑎 or 𝑏, implying 𝑥|𝑎 or 𝑥|𝑏.

□

3.3. Factoring in ℤ[𝑥]

Definition 18. Let 𝑓(𝑥)∈ℤ[𝑥] be a polynomial with positive leading coefficient and degree at least . Call 𝑓 primitive if the coefficients of 𝑓(𝑥) do not share a common factor.

We have not yet made any statements on primality or irreducibility of primitive polynomials

Lemma 13.
  1. 𝑓(𝑥)∈ℤ[𝑥] is primitive if and only if it is nonzero under the projection map ℤ[𝑥]→𝔽𝑝[𝑥], sending 𝑓 to 𝑓‾, for all primes 𝑝.
  2. Let 𝑓(𝑥)∈ℚ(𝑥). Then 𝑓(𝑥) can uniquely be written as 𝑐𝑓0(𝑥) with 𝑐∈ℚ and 𝑓0∈ℤ[𝑥] primitive.
  3. If 𝑓(𝑥)∈ℤ[𝑥], then 𝑐∈ℤ[𝑥]
Proof
  1. By definition.
  2. Let 𝑐0 be the product of the denominators, and multiply this by the gcd of the integer coefficients in 𝑐0𝑓(𝑥) to get 𝑐. Proof of uniqueness: 𝑐1𝑓1=𝑐2𝑓2⟹𝑐1𝑐2𝑓1=𝑓2. We must have 𝑐1𝑐2=1 since both 𝑓1 and 𝑓2 are primitive.
  3. Follow the construction procedure and invoke uniqueness.

□

Lemma 14 (Gauss's Lemma). If 𝑓,𝑔∈ℤ[𝑥] are primitive. Then, so is 𝑓⋅𝑔.
Proof
The leading coefficent of 𝑓⋅𝑔 is greater than zero. 𝑓‾⋅𝑔‾∈𝔽𝑝[𝑥] is nonzero, since both 𝑓‾ and 𝑔‾ are, and 𝔽𝑝[𝑥] is an integral domain. Hence 𝑓⋅𝑔 is primitive by Lemma 13.

□

Lemma 15 (Polynomial division in ℤ[𝑥] yields integer coefficients). Let 𝑓0,𝑔∈ℤ[𝑥] with 𝑓0 primitive. If 𝑓0 divides 𝑔 in ℚ[𝑥], say 𝑔=𝑓0𝑞, then 𝑞∈ℤ[𝑥], and thus 𝑓0 divides 𝑔∈ℤ[𝑥] as well.
Proof
Let 𝑔=𝑓0𝑞∈ℚ[𝑥], and let 𝑔=𝑐𝑔0 and 𝑞=𝑑𝑞0 with 𝑐,𝑑∈ℚ, invoking (2) in Lemma 13. Since 𝑔∈ℤ[𝑥], we have 𝑐∈ℤ. We have 𝑐𝑔0=𝑑𝑓0𝑞0. By Gauss’s lemma, 𝑓0𝑞0 is primitive, so we must have 𝑐=𝑑 and 𝑔0=𝑓0𝑞0 by uniqueness. Thus 𝑞=𝑐𝑞0∈ℤ[𝑥].

□

Corollary 1 ⭐️⭐️⭐️⭐️⭐️.

  1. Let 𝑝∈ℤ[𝑥]. 𝑝 is reducible in ℚ[𝑥] implies 𝑝 is reducible in ℤ[𝑥], or equivalently, 𝑝 is irreducible in ℤ[𝑥] implies 𝑝 irreducible in ℚ[𝑥]. The converse is not necessarily true, since 2𝑥+2=2(𝑥+1) in ℤ[𝑥] but 2 is a unit in ℚ[𝑥].
  2. Let 𝑝∈ℤ[𝑥] be primitive. Then 𝑝 is irreducible in ℤ[𝑥] if and only if it is irreducible in ℚ[𝑥].

Corollary 2. (Rational root theorem). If 𝑥=𝑝𝑞 is a root of a polynomial 𝑝∈ℤ[𝑥], then the primitive (𝑞𝑥−𝑝) must divide 𝑝. Use the fact that the divisor is also in ℤ[𝑥].

Theorem 6.
  1. The irreducible elements in ℤ[𝑥] with positive leading coefficients are: prime integers 𝑝 and the primitive polynomials 𝑓 that are irreducible in ℚ[𝑥].
  2. These are also prime elements of ℤ[𝑥].
  3. ℤ[𝑥] is a UFD, i.e. any polynomial admits a unique factorization into irreducible (prime) elements.
Proof
  1. Suppose 𝑓 is irreducible in ℤ[𝑥]. Then, regarded as polynomial in ℚ, we have 𝑓=𝑐𝑓0 for some primitive polynomial 𝑓0∈ℤ[𝑥] and 𝑐∈ℤ. Since 𝑓 is irreducible, we must have 𝑐=1, implying that 𝑓 is primitive. Next by lem_QQdivision, irreducibility in ℤ[𝑥] implies irreducibility in ℚ[𝑥]. Use Corollary 1 for the backwards proof.
  2. Suppose 𝑓0|𝑔ℎ in ℤ[𝑥]. Write 𝑔=𝑐𝑔0 and ℎ=𝑑ℎ0 for integers 𝑐,𝑑. Then 𝑓0|𝑔0ℎ0 in ℚ[𝑥] and thus 𝑓0|𝑔0 or 𝑓0|ℎ0 in ℚ[𝑥] since ℚ[𝑥] is a PID (Lemma 12). By lem_QQdivision, 𝑓0|𝑔 in ℤ[𝑥], showing that 𝑓0 is prime.
  3. Let 𝑓∈ℤ[𝑥] be a polynomial. Write 𝑓=𝑐𝑓0 where 𝑓 is primitive. We can uniquely factor 𝑐 since ℤ is a UFD. Viewed in ℚ[𝑥] (PID ⇒ UFD), we can factor 𝑓 into irreducibles. Reducibility in ℚ[𝑥] implies reducibility in ℤ[𝑥], and we can invoke (1) to show that these factors are irreducible in ℤ[𝑥]. To prove uniqueness, let 𝑓=𝑐𝑝1𝑝2…𝑝𝑛=𝑑𝑞1𝑞2…𝑞𝑚. Again, view this in ℚ[𝑥]. Since ℚ[𝑥] is a UFD, these factorizations are unique, implying the same in ℤ[𝑥].

□

Theorem 7 (Polynomial ring is a UFD). More generally, if 𝑅 is a UFD, then 𝑅[𝑥] is also a UFD.
Proof
Proceed by induction on the degree of 𝑛. The base case is satisfied by hypothesis that 𝑅 is a UFD. Suppose 𝑓(𝑥)=𝑟0+𝑟1𝑥+…+𝑟𝑛𝑥𝑛. Suppose 𝑟0 admits a unique factorization 𝑟0=𝑖1…𝑖𝑘. We proceed in the exact same manner with ℤ and ℚ, using 𝑅 and it’s fraction field 𝐹𝑅.

□

3.4. Gauss primes

The Gauss integers ℤ[𝑖] form a PID and thus a UFD. Prime elements of ℤ[𝑖] are called Gauss primes.

For example, 2 and 5 are not Gauss primes, but (1±𝑖),(2±𝑖),3,7 are.

Lemma 16. Let 𝑝 be an odd prime, and let 𝐺=𝔽𝑝×, which has order 𝑝−1.
  1. 𝐺 contains an element of order 𝑝 iff 𝑝≡1mod4.
  2. 𝑎∈𝐺 has order 4 if and only if 𝜑(𝑎)=−1.
Proof
  1. Forward is obvious by Lagrange. Suppose 𝑝≡1mod4. Consider the endomorphism 𝜑:𝑎↦𝑎2. Then ker𝜑={±1} and |im𝜑|=𝑝−12. By Cauchy’s theorem, im𝜑 has an element of order 2 if and only if 𝑝≡1mod4
  2. Obvious

□

Lemma 17. An integer prime 𝑝∈ℤ is either a Gauss prime or a product 𝜋‾𝜋 of a Gauss prime 𝜋∈ℤ[𝑖].
Proof
Since ℤ[𝑖] is a PID, we can factor 𝑝=𝜋1𝜋2…𝜋𝑘 where 𝜋𝑖 are Gauss primes. Thus 𝑝2 is divisble by some integer 𝜋‾𝜋 in ℤ[𝑖] and ℤ. Thus 𝜋‾𝜋 either equals 𝑝 or 𝑝2. If 𝜋‾𝜋=𝑝2, then 𝜋 and 𝑝 are associates since ℤ[𝑖] is a UFD. Thus 𝑝 is a Gauss prime. If 𝜋‾𝜋=𝑝, then the second case is achieved.

□

Theorem 8. Let 𝑝 be an odd prime integer. The following are equivalent:
  1. There exists a Gauss prime 𝜋 such that 𝑝=𝜋‾𝜋
  2. 𝑝=𝑎2+𝑏2, sum of squares of 𝑎,𝑏∈ℤ.
  3. 𝑝≡1mod4.
  4. −1 is a square in 𝔽𝑝.
Proof

(1)↔(2) is obvious. (3)↔4 is proved by the first lemma.

(1)↔(4). By lem_ππ, it suffices to show 𝑝 is a Gauss prime if and only if (−1) is not a square in 𝔽𝑝. Suppose 𝑝 is a Gauss prime. Since ℤ[𝑖] is a PID this occurs only if 𝑝 is irreducible and thus (𝑝) is maximal. This occurs if and only if ℤ[𝑖]/(𝑝) is an field, and ℤ[𝑥]/(𝑝,𝑥2+1)≅𝔽𝑝/(𝑥2+1). This occurs if and only if (𝛼2+1) is irreducible in 𝔽𝑝[𝑥], which occurs if and only if (−1) is not a square in 𝔽𝑝 (since then we must have 𝑥2+1=(𝑥−𝑎)(𝑥−𝑏) implying it has roots, or equivalently, 𝑥2+1≡0mod𝑝)

□

3.5. Factoring Polynomials

Irreducibility in ℤ[𝑥] implies irreducibilty in 𝔽𝑝[𝑥]. This can be used to for factorizing polynomials in ℤ[𝑥].

Example 4. Show that 𝑥4+15𝑥+32 and 𝑥5+𝑥3+𝑥2+𝑥+1 are irreducible in ℤ[𝑥].
  1. 𝑥4+15𝑥+32. Take mod 5 to get 𝑥4+2, which has no linear or quadratic factors (check with bash, 𝑥4+4 does by Sophie-Germain).
  2. 𝑓(𝑥)=𝑥5+𝑥3+𝑥2+𝑥+1. Take mod2 to conclude 𝑓(0)≡𝑓(1)≡1. Thus there is no linear factor modulo 2 since we’d either need (𝑥−0) or (𝑥−1) divides 𝑓(𝑥). Thus check polynomials of degree 2. 𝑥2+𝑥+1 is the only irreducible polynomial of degree 2 in 𝔽2[𝑥], and it does not divide 𝑓. Hence 𝑓 is irreducible.
Proposition 18 (Eisenstein Criterion). Let 𝑓(𝑥)=𝑎𝑛𝑥𝑛+…+𝑎0∈ℤ[𝑥] and 𝑝 be prime. Suppose
  1. 𝑝∤𝑎𝑛
  2. 𝑝∣𝑎𝑗,𝑗=0,..,𝑛−1
  3. 𝑝2∤𝑎0.
Then 𝑓 is irreducible in ℤ[𝑥] and ℚ[𝑥].
Proof
Mod 𝑝, we have 𝑓(𝑥)≡𝑎𝑛𝑥𝑛. Suppose 𝑓=𝑔ℎ. We must have 𝑔(𝑥)≡𝑏𝑚𝑥𝑚 and ℎ(𝑥)≡𝑐𝑙𝑥𝑙. Thus 𝑏0≡𝑐0≡0mod𝑝, which implies 𝑝2∣𝑎0. This is a contradiction, hence 𝑓 is irreducible.

□

Proposition 19. The cyclotomic polynomial 𝜙(𝑥)=𝑥𝑝−1+𝑥𝑝−2+⋯+𝑥+1 is irreducible in ℤ[𝑥] and ℚ[𝑥] when 𝑝 is prime.
Proof

We have 𝑥𝑝−1=(𝑥−1)𝜙(𝑥) and let 𝑥=𝑦+1. Note that Φ(𝑥) is irreducible if and only if Φ(𝑦+1) is irreducible. We get (𝑦+1)𝑝−1=𝑦𝜙(𝑦+1). We get

𝑦𝑝+(𝑝1)𝑦𝑝−1+⋯+(𝑝𝑝−1)𝑦+1−1=𝑦𝜙(𝑦+1). (30)
Dividing the both sides by 𝑝 shows that 𝜙(𝑦+1) satisfies the Eisenstein criterion.

□
