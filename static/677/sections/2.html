2. Probability Spaces

2.1. Motivation

In discrete settings, it’s easy to define probability as the number of favorable outcomes over total outcomes |Ω|. In continuous spaces like Ω=[0,1] that logic breaks. You can’t assign uniform probability to every subset of [0,1] (Vitali paradox). Hence we need to restrict ourself to a collection of “well-behaved” subsets where a consistent definition is possible. Measure theory seeks to explore this.

2.2. Measures

Definition 2 (𝜎-field). Given a sample space Ω, a 𝜎-field is a collection ℱ︀ of subsets of Ω, with the following properties:
  1. Ø∈ℱ︀
  2. Closure under complements: If 𝐴∈ℱ︀, then 𝐴𝑐 in ℱ︀.
  3. Closure under countable unions: If 𝐴𝑖∈ℱ︀ for every 𝑖∈ℕ, then ∪𝑖=1∞𝐴𝑖∈ℱ︀ .
A set 𝐴∈ℱ︀ is called an event1 or an ℱ︀-measurable set. The pair (Ω,ℱ︀) is called a measurable space.

The intersection of σ-fields is a σ-field. We can use this to construct the “smallest” σ-field containing a collection of subsets 𝒜︀ of Ω by taking the intersection of all σ-fields containing 𝒜︀. There always exists a 𝜎-field containing a collection of subsets 𝒜︀ (take 2Ω for example). This is a well-defined construction and is called the 𝜎-field generated by 𝒜︀, denoted 𝜎(𝒜︀).

If we relax the countable unions property to only finite unions, then we get a field of sets.

Definition 3 (Measure). Let (Ω,ℱ︀) be a measurable space. A measure is a function 𝜇:ℱ︀→[0,∞], which assigns a nonnegative extended real number 𝜇(𝐴) to every set 𝐴∈ℱ︀, and which satisfies the following two conditions:

  1. 𝜇(Ø)=0.
  2. Countable additivity: If {𝐴𝑖} is a countable sequence of disjoint sets that belong to ℱ︀, then 𝜇(∪𝑖𝐴𝑖)=∑𝑖∞𝜇(𝐴𝑖).

A probability measure is a measure ℙ with the additional property that ℙ(Ω)=1. In that case, the triple (Ω,ℱ︀,ℙ) is called a probability space.

If an event 𝐴∈ℱ︀ satisfies ℙ(𝐴)=1, we say that 𝐴 occurs almost surely.

The fact that we use probability measures to represent probability the same thing as the Kolmogorov axioms.

Every measurable space admits a trivial measure. Every measurable space also admits a probability measure: Take any 𝑥∈Ω, and let ℙ(𝐴)=1 if 𝑥∈𝐴 otherwise 0. This is called a Dirac measure. The problem is that not every measurable space admits a nice probability measure. For example, if we let Ω=[0,1],ℱ︀=2Ω, there does not exist a uniform measure satisfying 𝜇([𝑎,𝑏])=𝑏−𝑎 (Vitali theorem).

Here is a trivial example of an almost sure event: let Ω={1,2,3} and 𝑝1=0.5,𝑝2=0.5,𝑝3=0. Then ℙ({1,2})=1.

Theorem 2 (Continuity of probability measures). Let ℱ︀ be a 𝜎-field of subsets of Ω, and suppose that ℙ:ℱ︀→[0,1] satisfies ℙ(Ω)=1 as well as the finite additivity property. Then, the following are equivalent:
  1. ℙ is a probability measure (satisfies countable additivity).
  2. If {𝐴𝑖} is an increasing sequence of sets in ℱ︀ and 𝐴=∪𝑖=1∞, then lim𝑖→∞ℙ(𝐴𝑖)=ℙ(𝐴).

Working with half-open intervals shows that this Borel field admits a uniform measure.

2.6. Completion of a Measurable Space

We have defined the Lebesgue measure that acts on the Borel sigma field (ℝ,ℬ︀). Is there a way to extend it?

Consider a measurable space (Ω,ℱ︀,𝜇). Suppose that 𝐵∈ℱ︀, and ℙ(ℬ︀)=0. Any set with this property is called a null set. We can extend the 𝜎-field by including all subsets of null sets (any such subset clearly requires measure 0).

  1. Let 𝒩︀ be the collection of all subsets of null sets.
  2. Define ℱ︀∗=𝜎(ℱ︀∪𝒩︀), the smallest 𝜎-field that contains ℱ︀as well as all subsets of null sets.
  3. It turns out we can uniquely extend 𝜇 to 𝜇∗ by letting 𝜇∗(𝐴)=0 for every subset 𝐴⊂𝐵 of every null set 𝐵∈ℱ︀.

The resulting probability space is said to be complete. All subsets of null sets are included in the 𝜎-field and are also null sets. When Ω=[0,1] or Ω=ℝ, ℱ︀ is the Borel σ-field, and 𝜇 is the Lebesgue measure, the sets in ℱ︀∗ are called Lebesgue measurable sets. The new measure is also called the Lebesgue measure.

Remarks

  • There exists sets that are Lebesgue measurable but not Borel measurable.
  • There are as many Borel measurable sets as there are points on the real line (cardinality of the continuum), but there are as many Lebesgue measurable sets as there are subsets of the real line (which is a higher cardinality).
  • There exists subsets of [0,1] that are not Lebesgue measurable.
  • It is not possible to construct a probability space in which the 𝜎-field includes all subsets of [0,1] with the probability that ℙ({𝑥})=0 for every 𝑥∈(0,1].

2.7. Vitali Sets and Banach-Tarski paradox.

Ordinary geometric intuition fails when dealing with arbitrary sets.

  1. We will give an example of a non-Lebesgue measurable set 𝐻 (Vitali set) and use it to show that if the Lebesgue measure could assign a length to all subsets of (0,1] and be translation-invariant, you would get a contradiction. Let + stand for addition modulo 1 in (0,1]. Define 𝑥 and 𝑦 to be equivalent if they differ by a rational number, and partition (0,1] into equivalence classes. Using axiom of choice, pick one element from each equivalence class and call this set 𝐻. Consider sets of the form 𝐻+𝑟 where 𝑟 is a rational. Such sets are translations of each other and disjoint. Suppose ℙ is a translation invariant probability measure. Then 1=ℙ((0,1])=∑𝑟ℙ(𝐻+𝑟)=∑𝑅ℙ(𝐻) but this can’t happen since 𝑟 is infinite. We can apply this to [0,1] by assigning 𝜇({0})=0.
  2. Banach-Tarski paradox: let 𝑆 be the 2D surface of the unit sphere in 3D. There exists a subset 𝐹 of 𝑆 such that for any 𝑘≥3, 𝑆=(𝜏1𝐹)∪⋯∪(𝜏𝑘𝐹), where each 𝜏𝑖 is a rigid rotation and the sets 𝜏𝑖𝐹 are disjoint. For example, 𝑆 can be made by three rotated copies of 𝐹 as well as four rotated copies of 𝐹, suggesting probability 1/3 and 1/4 simultaneously. The full Banach-Tarski paradox says: a solid ball can be decomposed into finitely many disjoint pieces that reassemble into two identical balls using rotations and translations. If we reject axiom of choice (equivalent to saying all vector spaces have a basis), BT paradox disappears!

  1. Two events 𝐴 and 𝐵 are said to be independent if ℙ(𝐴∩𝐵)=ℙ(𝐴)ℙ(𝐵). If ℙ(𝐵)>0, an equivalent condition3 is ℙ(𝐴)=ℙ(𝐴|𝐵).

  3. Let ℱ︀1,ℱ︀2⊂ℱ︀ be two 𝜎-fields. We say ℱ︀1 and ℱ︀2 are independent if for any two events 𝐴1∈ℱ︀1 and 𝐴2∈ℱ︀2 are independent.
  4. More generally, let 𝑆 be an index set of 𝜎-fields ℱ︀𝑠. The 𝜎-fields ℱ︀𝑠 are independent if the following holds: if we pick one event 𝐴𝑠 from each 𝐹𝑠, the events in the resulting family 𝐴𝑠|𝑠∈𝑆 are independent.

For example, when 𝐴∩𝐵=0, 𝐴 and 𝐵 are not independent since knowing 𝐴 guarantees 𝐵=0. Similarly when 𝐴=𝐵 they are not independent.

2.9. Borel-Cantelli

The Borel-Cantelli lemma helps us establish that a certain event has probability zero or one.

Definition 6 (Infinitely Often). Given a sequence of events {𝐴𝑛}, the event {𝐴𝑛i.o.} (read as “𝐴𝑛 occurs infinitely often”) is defined to be the event consisting of all 𝜔∈Ω that belong to infinitely many 𝐴𝑛. Equivalently,

{𝐴𝑛i.o.}=⋂𝑛=1∞⋃𝑖=𝑛∞𝐴𝑖 (12)

The limit inferior means “eventually always true”:

liminf𝐴𝑛=⋃𝑛=1∞⋂𝑖=𝑛∞𝐴𝑖 (13)

Applying De Morgan’s law twice implies that

(liminf𝐴𝑛)𝑐=limsup𝐴𝑛𝑐 (14)

I.e. if 𝐴𝑛𝑐 never eventually is always true then we must have infinitely many 𝐴𝑛 occur.

(limsup𝐴𝑛)𝑐=liminf𝐴𝑛𝑐 (15)

I.e. if only finitely many 𝐴𝑛 occur then eventually 𝐴𝑛𝑐 must always occur.

The outer intersection means “for every 𝑛” and the inner union means “there exists 𝐴𝑖≥𝑛 containing 𝑥”. In set theory we also denote this as limsup𝑛→∞𝐴𝑛. Hence 𝐴 is the event that infinitely many 𝐴𝑛 occur.

  1. If ∑𝑛=1∞ℙ(𝐴𝑛)<∞, then ℙ(𝐴)=0.
  2. If ∑𝑛=1∞ℙ(𝐴𝑛)=∞ and the events {𝐴𝑛} are independent, then ℙ(𝐴)=1.
Proof
  1. ∑𝑛=1∞ℙ(𝐴𝑛)<∞ implies that lim𝑛→∞∑𝑖=𝑛∞ℙ(𝐴𝑖)=0. Note that for every 𝑛, we have 𝐴⊂∪𝑖=𝑛∞𝐴𝑖. Apply union bound and take the limit as 𝑛→∞.

  2. Let 𝐵𝑛=∪𝑖=𝑛∞𝐴𝑖 so that 𝐴=∩𝑛=1∞𝐵𝑛. It suffices to show that ℙ(𝐵𝑛𝑐)=0 for all 𝑛 since then

    ℙ(𝐴𝑐)=ℙ(∪𝑛=1∞𝐵𝑛𝑐)≤∑𝑛=1∞ℙ(𝐵𝑛𝑐)=0 (16)

    by union bound. Independence of {𝐴𝑖} implies independence of {𝐴𝑖𝑐}, so we have

    ℙ(𝐵𝑛𝑐)=lim𝑚→∞∏𝑖=𝑛𝑚(1−ℙ(𝐴𝑖)). (17)

    The RHS equals zero by the following lemma: Suppose that 0≤𝑝𝑖≤1 for every 𝑖∈𝑁, and that ∑𝑖=1∞𝑝𝑖=∞. Then ∏𝑖=1∞(1−𝑝𝑖)=0. The lemma is proved by taking the logarithm and showing log(1−𝑥)≤−𝑥 for 𝑥∈[0,1]. Use the fact that log(1−𝑥) is concave so the graph lies below every tangent line.
