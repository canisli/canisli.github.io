5. More Group Theory

5.1. Group Actions

  • Def Given group 𝐺 and finite set 𝑋, a group action of 𝐺 on 𝑋 is a map 𝑎:𝐺×𝑋→𝑋 satisfying
    1. 𝑒∘𝑥=𝑥 (Identity)
    2. (𝑔ℎ)∘𝑥=𝑔(ℎ𝑥) (Compatilibity)
    • Ex If a group acts by left or right multiplication, we must have 𝑔∘𝑥=𝑔𝑥 and 𝑔∘𝑥=𝑔𝑥−1, respectively.
    • Prop (Equivalent Definition) For a given 𝑔, a group action defines a homomorphism 𝜋:𝐺→Perm𝑋. Conversely, if 𝐺→Perm𝑋 is a homomorphism, we can define a group action.

  • Def

    Orb𝑥={𝑔𝑥|𝑔∈𝐺},Stab𝑥={𝑔∈𝐺|𝑔𝑥=𝑥}. (29)

  • Prop (Orbit–Stabilizer) There is natural bijective mapping between 𝐺/Stab𝑥 and Orb𝑥 given by

    𝜑:𝐺/Stab𝑥→Orb𝑥𝜑(𝑔Stab𝑥)=𝑔𝑥. (30)
    ∴[𝐺:Stab𝑥]=|Orb𝑥|. (31)

    • Cor For all 𝑥∈𝑋 we have

      |𝐺|=|Stab𝑥||Orb𝑥|. (32)
    • Prop Stabilizers in the same orbit are isomorphic. In particular, let 𝑥,𝑦∈𝑋 belong to the same orbit, where 𝑔𝑥=𝑦. Then Stab𝑦=𝑔(Stab𝑥)𝑔−1.
  • Classifying actions
    • Def An action is transitive if there is only one orbit.
      • By orbit-stabilizer, |𝐺| must be a multiple of |𝑋|.
    • Def An action is faithful if each non-identity element acts non-trivially on 𝑋, i.e. the homomorphism 𝜋:𝐺→𝑆|𝑋| is injective.
      • Equivalent definition: the intersection of all the stabilizers is identity.
    • Def An action is free when there are no nontrivial stabilizers.
      • Then each orbit has size |𝐺|.
      • Ex. SO2 acts freely on ℝ2\0.
    • Ex Group action ℤ15 acting on a set 𝑋 of 7 elements.
      • By orbit-stabilizer, the orbits must have size dividing 15, so the orbits must have size 1, 3, or 5. 𝐺 acts transitively on an orbit, so
      • Such action cannot be transitive; 15 is not a multiple of 7. It cannot be faithful, there is no subgroup of order 15 in 𝑆7. It cannot be free, 15>7.
    • Prop If a group 𝐺 has a subgroup of index 𝑚, then there exists a homomorphism from 𝐺 to 𝑆𝑚.
      • Ex There does not exist a subgroup of 𝐴5 of order 15, since a homomorphism from 𝐴5 to 𝑆4 would have nontrivial kernel but 𝐴5 is simple.

5.2. Fundamental Examples

  1. Ex Subgroup 𝑯<𝑮 acting on 𝑮 (Cosets)

    • Let 𝐻 act on 𝐺 via right multiplication:

      𝑎(ℎ,𝑥)=𝑥ℎ−1. (33)
      • The orbits are cosets. This is a free action.
      • 𝐺 acts transitively on the set of cosets 𝐺/𝐻.
  2. Ex 𝑮 acts transitively on 𝑮/𝑯 (Cosets)
    • Let 𝐻⊂𝐺 be a subgroup of index 𝑚, and let 𝐺 act on 𝐺/𝐻 via left multiplication.
      • Thus there exists a homomorphism from 𝐺→𝑆𝑚
      • The image is a subgroup of 𝑆𝑚. Using the fact that [𝐺:ker𝜑]=|im𝜑| yields the following proposition:
      • Prop10 If a group 𝐺 has a subgroup 𝐻 of index 𝑚, then it has a normal subgroup contained in 𝐻 and of index at most 𝑚!.
        Proof. Consider 𝐺 acting on 𝐺/𝐻 via left multiplication. Let 𝑚=[𝐺:𝐻]. Then 𝐺/ker𝜑 is isomorphic to a subgroup of 𝑆𝑚. Furthermore, the ker𝜑 is contained in 𝐻 (it is not equal to 𝐻 since 𝐻 is not necessarily normal. In particular, 𝑥𝑎𝐻=𝑎𝐻 requires 𝑎𝑥𝑎−1∈𝐻).
        • Ex 𝐴5 has no subgroup of order 15. Suppose there was a subgroup of index 4. Since 4!<60, there would be a nontrivial normal subgroup of 𝐴5, contradiction.

        • [∗] Cor11 Suppose 𝐻⊂𝐺 has index 𝑝 where 𝑝 is the smallest prime dividing 𝐺. Then 𝐻 is normal.
          Hint. Consider 𝐾 the normal subgroup contained in 𝐻, and consider

          [𝐺:𝐾]=[𝐺:𝐻][𝐻:𝐾]. (34)

  3. Ex 𝑮 acting on itself (Conjugacy classes)

    • Let 𝐺 act on itself by conjugation:

      𝑎(𝑔,𝑥)=𝑔𝑥𝑔−1. (35)
      • Def The orbits are conjugacy classes. The stabilizer is the centralizer 𝑍𝑥, the set of elements that commute with 𝑥. This that implies that elements in the same conjugacy class commute with the same amount of elements.
      • Orbit-stabilizer gives us a relationship between conjugacy classes and commuting elements!
    • We have a class equation:
    |𝐺|=∑𝑖|𝐶𝑖|=∑𝑖|𝐺||𝑍𝑖| (36)
    • Ex 𝐺=𝑆3, 6=1+3+2, 1=16+12+13
  4. Ex 𝑮 acting on the set of its subgroups

    • Let 𝐺 act on 𝐻 via subgroup conjugation:

      𝑔∘𝐻=𝑔𝐻𝑔−1. (37)
      • Def The stabilizer of 𝐻 is the normalizer of 𝐻. It is the largest subgroup of 𝐺 containing 𝐻 where 𝐻 is normal.

    • Prop (Cayley’s Theorem) Left multiplication is injective, thus every group of order 𝑛 is isomorphic to a subgroup of 𝑆𝑛.

5.5. Simplicity of the alternating group

  • Def A group is simple if it has no nontrivial normal subgroups other than itself.
    • Ex 𝐴5 is simple. A nontrivial normal subgroup is the union of conjugacy classes including {𝑒}. No such union has a size that divides |𝐴5|.
    • Ex 𝐴4 is not simple. The Klein four group inside it is normal.
  • Lem 1. For 𝑛≥4, 𝐴𝑛acts transitively on the set of ordered pairs {(𝑝,𝑞)|𝑝≠𝑞,1≤𝑝,𝑞≤𝑛}.
    Proof. For any (𝑝′,𝑞′), the permutation (𝑝𝑝′)(𝑞𝑞′)∈𝐴𝑛 does the job.
    • Lem 2. For 𝑛≥4, the centralizer of 𝐴𝑛 in 𝐴𝑛+2 is trivial. In other words, there is no element in 𝑆𝑛 that commutes with every element of 𝐴𝑛.
    Proof. Suppose 𝑠∈𝐴𝑛+2 commutes with 𝐴𝑛. Then for all 𝑖≤𝑛 we have 𝑠(𝑖)≤𝑛. I claim that 𝑠(𝑖)=𝑖 for all 𝑖≤𝑛. Suppose there is an 𝑖 such that 𝑠(𝑖)≠𝑖. Then there exists 𝑔∈𝐴𝑛 such that 𝑔(𝑖)=𝑖 and 𝑔(𝑠(𝑖))=𝑗≠𝑠(𝑖). 𝑔 does not commute with 𝑠 and we have a contradiction. □
  • Thm 𝐴𝑛 is simple for 𝑛>5.
    Proof. Proceed by induction on 𝑛. Suppose 𝐻 is a normal subgroup of 𝐴𝑛, take any ℎ∈𝐻. First, suppose ℎ has a fixed point. WLOG since 𝐻 is normal we can set ℎ(𝑛)=𝑛. Then ℎ can be embedded into 𝐴𝑛−1. By the induction hypothesis, 𝐴𝑛−1⊂𝐻. So 𝐻 contains all the three cycles and equals 𝐴𝑛. Suppose there is no ℎ∈𝐻 with a fixed point. WLOG we can have ℎ(𝑛)=𝑛−1. By Lem 2 there exists a nontrivial 𝑠∈𝐴𝑛−2 such that 𝑠ℎ≠ℎ𝑠, so 𝑔=𝑠−1ℎ−1ℎ𝑠≠𝑒. But 𝑔(𝑛)=𝑛, so this reduces to the first case. □

5.6. 𝑝-groups

  • Def A 𝑝-group is a group of order 𝑝𝑛 where 𝑝 is prime.
  • Prop14 Every 𝑝-group has a nontrivial center.
  • Prop (Fixed point theorem) More generally, if a 𝑝-group acts on set 𝑋 and |𝑋|≢0mod𝑝 then ∃𝑥∈𝑋 such that 𝑥 is fixed by 𝐺.

  • Lem 1. 𝐺/𝑍(𝐺) being cyclic implies 𝐺 is abelian.
    Proof. Suppose 𝐺/𝑍(𝐺)=⟨𝑥𝑍(𝐺)⟩. Every element can be expressed in the form 𝑥𝑎𝑧 for some z in 𝑍(𝐺). Then

    𝑔ℎ=(𝑥𝑎1𝑧1)(𝑥𝑎2𝑧2)=(𝑥𝑎2𝑧2)(𝑥𝑎1𝑧1)=ℎ𝑔 (41)
  • Lem 2. (Restated from my 5.2.2) Subgroups of index 2 are normal. More generally, subgroups of index 𝑝 where 𝑝 is the smallest prime dividing |𝐺| are normal.

  • Thm Every group of order 𝑝2 is abelian, namely either ℤ𝑝2 or ℤ𝑝×ℤ𝑝.
    Proof. Suppose 𝐺 contains an element of order 𝑝2. Then it is isomorphic to ℤ𝑝2. Otherwise, suppose all nontrivial elements of 𝐺 have order 𝑝. Take a nontrivial element 𝑧∈𝑍(𝐺). ⟨𝑧⟩ has order 𝑝 and is normal by Lem 2. Take 𝑎∈𝐺\⟨𝑧⟩. Then 𝐺=⟨𝑎,𝑧⟩ since the RHS is a subgroup with order larger than 𝑝. But 𝑎𝑧=𝑧𝑎, so 𝐺=𝐻𝐾 where 𝐻=⟨𝑎⟩ and 𝐾=⟨𝑧⟩. Since 𝐻 and 𝐾 are both normal and 𝐻∩𝐾={𝑒}, 𝐺≅𝐻×𝐾=ℤ𝑝×ℤ𝑝.

    We could have used Lem 1 to show abelianness quickly.

    • Ex We can have nonabelian groups for higher powers. The Heisenberg group is a nonabelian 𝑝-group of order 𝑝3.

5.7. Sylow Theorems

  • Def Suppose 𝐺 is a finite group of order 𝑝𝑒𝑚 and gcd(𝑝,𝑚)=1, i.e. 𝑝𝑒 is the largest power of prime 𝑝 that divides |𝐺|. 𝐻<𝐺 is a 𝑝-Sylow subgroup if |𝐻|=𝑝𝑒.
  • Prop Let 𝑆 be the set of subsets of 𝐺 of size 𝑥. 𝐺 acts freely on 𝑆 via left multiplication.

    • Lem 1. Let 𝑈⊂𝐺 be a subset of 𝐺. Then |Stab𝑈| divides both |𝑈| and |𝐺|.

      Proof. Observe that Stab𝑈 acts freely on both 𝐺 and 𝑈via left multiplication.

    Proof.

    (𝑝𝑒𝑚𝑝𝑒)=𝑝𝑒𝑚𝑝𝑒∏𝑘=1𝑝𝑒−1𝑝𝑒(𝑚−1)+𝑘𝑘=𝑚∏𝑘=1𝑝𝑒−1(1+𝑝𝑒(𝑚−1)𝑘)≡𝑚mod𝑝. (42)

    • Cor (Cauchy) If |𝐺| is divisible by prime 𝑝 then 𝐺 contains an element of order 𝑝.

      Pf. Let 𝐻 be a 𝑝-Sylow subgroup of 𝐺, and take any nontrivial 𝑔∈𝐻 so that |𝑔|=𝑝𝑟 for 𝑟≥1. Then 𝑔𝑝𝑟−1 has order 𝑝.

5.8. Groups of order 𝑝𝑞

Thm Groups of order |𝐺|=𝑝𝑞 where 𝑝<𝑞 and 𝑝,𝑞 are prime have one of the following structures:

  1. If 𝑝∤𝑞−1, 𝐺 is cyclic:

  2. If 𝑝∣𝑞−1, 𝐺 is cyclic or has a unique nonabelian structure:

    𝐺=ℤ𝑞⋊ℤ𝑝=⟨𝑎,𝑏|𝑎𝑝=𝑏𝑞=𝑒, 𝑎𝑏𝑎−1=𝑏𝑛⟩ (43)
    where 𝑛≠1 and 𝑛𝑝≡1mod𝑞.

Proof.
Let 𝑄 and 𝐻 be 𝑝- and 𝑞-Sylow groups of 𝐺, respectively. 𝐻 and 𝑄 are both cyclic since they have prime order, and 𝐻∩𝐾={𝑒} because the nontrivial elements in 𝐻 and 𝐾 have different orders. There can only be 1 𝑞-Sylow subgroup, implying 𝐻 is normal. By the proposition on product of subgroups, 𝐻𝐾 is a subgroup of 𝐺, and there exists a biijection between 𝐻𝐾 and 𝐻×𝐾. Thus |𝐻𝐾|=|𝐻‖𝐾|=|𝐺|, implying 𝐻𝐾=𝐺 and there exists a bijection between 𝐻×𝐾 and 𝐺.

In case 1, there can only be 1 𝑝-Sylow subgroup and 1 𝑞-Sylow subgroup, implying they are both normal and that the product map 𝑓:𝐻×𝐾→𝐺 is an isomorphism. Thus 𝐺≅𝐻×𝐾=ℤ𝑞×ℤ𝑝.

In case 2, consider when there are 𝑞 𝑝-Sylow subgroups. Thus

𝐺=⟨𝑎,𝑏⟩ (44)

where 𝑎𝑝=𝑏𝑞=𝑒,𝑎𝑏𝑎−1=𝑏𝑛 for some 𝑛. What are the allowed values of 𝑛? Note that

𝑎𝑝𝑏𝑎−𝑝=𝑏=𝑏𝑛𝑝, (45)

so we must have 𝑛𝑝≡1mod𝑞. 𝑛=1 reduces to the abelian case, i.e. case 1.
