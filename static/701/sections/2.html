2. Fields and Vector Spaces

2.1. Definition

  • Def A field 𝔽 is a set with two laws of compositiion called addition and multiplication such that
    1. 𝔽 equipped with addition is an abelian group with identity denoted as 0.
    2. Multiplication is commutative. 𝔽\{0} equipped with multiplication is an abelian group with identity denoted as 1.
    3. Distributive law holds.
  • Prop 𝑎𝑏=0 if and only if either 𝑎 or 𝑏=0. (This isn’t obvious from the definition!)
  • Prop 𝔽𝑝 is a field if and only if 𝑝 is prime.
  • Def A vector space 𝑉 over a field 𝔽 is a set with addition 𝑉×𝑉→𝑉 and scalar multiplication 𝔽×𝑉→𝑉 defined such that
    • 𝑉 equipped with addition is an abelian group with identity denoted as 0.
    • Scalar multiplication is associative and distributive over addition.
    • 1𝑣=𝑣 for all 𝑣 where 1∈𝔽.

2.2. Characteristic of a field

  • Prop Two bases of a finite-dimensional vector space have the same cardinality.
    • Remark. The same holds for an infinite-dimensional vector space.

    Proof. Pick a basis of 𝑉. There is a bijection 𝔽𝑛↔𝑉 given by (𝑎1,…,𝑎𝑛)↦𝑎1𝑣1+⋯+𝑎𝑛𝑣𝑛.

2.4. Linear transformations

  • Every vector space is an abelian group under addition. Then, linear transformations are homomorphisms of vector spaces.
  • Prop. Let 𝐴:𝔽𝑛→𝑉 be a linear map. Then 𝐴 is an isomorphism if and only if 𝐴𝑒𝑖=𝑣𝑖 form a basis of 𝑉.
  • Prop. Two vector spaces are isomorphic if and only if they have the same dimension.
