Traverals include in-order, pre-order, and post-order.

The minimum is not necessarily a leaf! Consider the following tree: Add 3, add 1, add 2.

Insertion algorithm Θ(ℎ).

  • Traverse the tree and add 𝑁 as a child where approriate.

Deletion algorithm Θ(ℎ).

  • If 𝑁 is a leaf, simply delete it.
  • Swap the node with its inorder successor/predecessor. Call the function recursively the new location of 𝑁.
