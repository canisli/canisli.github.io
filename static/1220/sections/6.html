6.2. Universal Hashing

If we fix a hash function ahead of time, an adversary can select a “bad” set of keys. If the hash function is chosen at random from a family of functions, we can avoid this. Python does this every time a hash table is constructed.

Definition 2. Let 𝑈 be a universe of keys, and let ℋ︀ be a collection of hash functions mapping 𝑈 to {0,…,𝑚−1}. ℋ︀ is universal if for all 𝑘,𝑘′∈𝑈 where 𝑘≠𝑘′,

|{ℎ∈ℋ︀:ℎ(𝑘)=ℎ(𝑘′)}|≤|ℋ︀|𝑚. (14)
I.e. the chance of collision between 𝑘 and 𝑘′ is less than 1𝑚 if ℎ is chosen randomly from ℋ︀.
Proposition 1. Choose ℎ randomly from ℋ︀, and suppose we wish to hash 𝑛 keys into 𝑚 slots in table 𝑇. For a given key 𝑘0, the expected number of collisions with 𝑘0 is less than 𝛼=𝑛/𝑚.
Proof
From above the expected number of collisions is less than or equal to 𝑛−1𝑚.

□

Some simple examples of universal hashes include a single constant function and the set of all functions.
