2. Divide and Conquer

Typically, we partition the problem into three subproblems, left, middle, and right. The middle subproblem contains overlap.

Theorem 1 (Master Theorem). Suppose 𝑇(𝑛) satisifes a recurrence of the form 𝑇(𝑛)=𝑎𝑇(𝑛/𝑏)+𝑓(𝑛). Let 𝑐crit=log𝑏𝑎.
  1. If 𝑓(𝑛)=𝑂(𝑛𝑐) for 𝑐<𝑐crit, then 𝑇(𝑛)=Θ(𝑛𝑐crit)
  2. If 𝑓(𝑛)=Θ(𝑛𝑐crit)(log𝑛)𝑘) for 𝑘≥0, then 𝑇(𝑛)=Θ(𝑛𝑐crit(log𝑛)𝑘+1).
  3. If 𝑓(𝑛)=Ω(𝑛𝑐) for 𝑐>𝑐crit, and the “regularity condition” holds (𝑎𝑓(𝑛/𝑏)≤𝑘𝑓(𝑛)) for some 𝑘<1), then 𝑇(𝑛)=Θ(𝑓(𝑛)).

2.2. Examples

  • Example 1. Maximum sum subarray problem. DP is the easiest and cleanest. We can also do a divide and conquer algorithm, where we check 3 different scenarios: subarray is in left half, subarray is in right half, or subarray is in both halves.
  • Example 2. Given a 2D point cloud, check whether any two points are within unit distance of each other. The higher dimensional case can be done with hashing pidgeonhole balls.
