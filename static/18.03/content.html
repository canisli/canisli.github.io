Proof

□

Theorem 2 (General First Order IVP). Let 𝑓 and 𝜕𝑓𝜕𝑦 be continuous in a rectangular region containing the point (𝑥0,𝑦0). Then in some interval around 𝑥0 there exists a unique solution to the IVP

1.2. The Wronskian

Definition 1 (Wronskian). The Wronskian of two differentiable functions is

𝑊(𝑥)=|𝑓(𝑥)𝑔(𝑥)𝑓′(𝑥)𝑔′(𝑥)|. (3)

Unfortunately, for general functions the Wronskian does not reveal linear dependence. In particular,

  1. 𝑊≠0 ⟹ 𝑓,𝑔 are independent.
  2. 𝑊=0 ⟹ 𝑓,𝑔 are dependent.
    • Example, Try 𝑓=𝑥2 and 𝑔=𝑥|𝑥|

Theorem 4 (Wronskian criterion for linear ODEs). If the two functions solve the second order linear ODE 𝑦″+𝑝(𝑥)𝑦′+𝑞(𝑥)𝑦=0, then

𝑊=0⟺𝑓,𝑔dependent. (4)
Proof

It suffices to show the Wronskian is zero then 𝑓,𝑔 are dependent. If 𝑓 or 𝑔 is zero, the theorem is obvious. Consider 𝑓(𝑥0)≠0 and the function

𝜙(𝑥)=−𝑔(𝑥0)𝑓(𝑥0)𝑓(𝑥)+𝑔(𝑥). (5)
By construction, 𝜙(𝑥0)=0 and since the Wronskian is zero, 𝜙′(𝑥0)=0. 𝜙 solves the original ODE, so by the existence and uniqueness theorem, 𝜙 must equal zero, implying 𝑓(𝑥) and 𝑔(𝑥) are scalar multiples of each other.

□

Remark. This extends to higher order ODEs.

2.3. Linear System

For 2×2 systems we have the following classes of solutions:

  1. Unstable saddle (𝜆1>0,𝜆2<0)
  2. Asymptotically stable node (𝜆1,𝜆2<0)
  3. Unstable node (𝜆1,𝜆2>0)
  4. Stable center (𝜆1,𝜆2imaginary)
  5. Asymptotically stable spiral (Re(𝜆1),Re(𝜆2)<0,Im(𝜆1)=Im(𝜆2)≠0)
  6. Unstable spiral (Re(𝜆1),Re(𝜆2)>0,Im(𝜆1)=Im(𝜆2)≠0)
  7. Asymptotically stable/unstable defective node (𝜆1=𝜆2, one generalized eigenvector)
    • Solution is 𝛂𝑒𝜆𝑡 and (𝛃+𝛂𝑡)𝑒𝜆𝑡 where 𝛃 is a generalized eigenvector.
  8. Star node (𝜆1=𝜆2, two eigenvectors)

  9. Degenerate solution (one eigenvector is zero)

    Note that stable solutions require negative trace and positive determinant. For pictures, see https://mathlets.org/mathlets/linear-phase-portraits-matrix-entry/.

  • Lokta-Volterra predator-prey model:
d𝑥d𝑡=𝑎𝑥−𝑏𝑥𝑦(prey)d𝑦d𝑡=−𝑐𝑦+𝑑𝑥𝑦(predator) (8)

Volterra’s principle states that if a constant proportion of both predator and prey populations are removed, the average number of predators will decrease relative to the average number of prey.

Theorem 8 (Fourier series convergence). Suppose that 𝑓 and 𝑓′ are continuous on the interval [−𝐿,𝐿), and 𝑓 is defined outside the interval so that it is periodic with period 2𝐿. Then 𝑓 has a Fourier series

𝑓(𝑥)=𝑎02+∑𝑚=1∞(𝑎𝑚cos𝑚𝜋𝑥𝐿+𝑏𝑚sin𝑚𝜋𝑥𝐿). (10)

  • Resonance occurs when the denominator equals zero or is near zero. This corresponds to when the frequency is near the resonant frequency of the system.
