4.3. Orthogonal complement and projection

Suppose 𝑈 is a subspace of 𝑉. We define the orthonormal complement of 𝑈 as

𝑈⟂={𝑣∈𝑉:⟨𝑣,𝑢⟩=0for every𝑢∈𝑈}. (12)

Theorem 4 (Orthogonal Complement). Suppose 𝑈 is a finite-dimensional subspace of 𝑉. Then

𝑈⊕𝑈⟂=𝑉 (13)
Proof

First we show that 𝑉=𝑈+𝑈⟂. Just take any orthonormal basis of 𝑈 and express

𝑣=⟨𝑣,𝑒1⟩𝑒1+…+⟨𝑣,𝑒𝑛⟩𝑒𝑛⏟∈𝑈+(𝑣−⟨𝑣,𝑒1⟩𝑒1−…−⟨𝑣,𝑒𝑛⟩𝑒𝑛)⏟∈𝑈⟂. (14)
To prove uniqueness, suppose 𝑣=𝑢1+𝑤1=𝑢2+𝑤2 where 𝑢𝑗∈𝑈 and 𝑤𝑗∈𝑈⟂. Then 𝑢1−𝑢2=𝑤2−𝑤1 where the LHS is in 𝑈 and the RHS is in 𝑈⟂. Since 𝑈∩𝑈⟂={0}, they must both equal zero.

Gram-schmidt, Orthogonal complement, and nullspace code

Runs in 𝑂(𝑟𝑐2) without the dumb 𝐶@𝐼 multiplication where 𝑟 is number of rows.and 𝑐 is the number of columns

def L2_norm(v):
    return np.vdot(v,v)**0.5

def gram_schmidt(vectors, *, tol=1e-8):
    """Return the Gram-Schmidt orthonormalization of the vectors.
    Input:
        vectors: an (n1, d) matrix of n1 complex vectors of dimension d
        tol: a tolerance for the zero vector
    Output:
        Q: an (n2, d) matrix of n2 orthonormal vectors, with n2 <= n1
        P: a (d, d) projector onto the span of the orthonormal vectors in Q
    """
    vectors = np.asarray(vectors, dtype=np.complex128)
    ortho_vectors = []
    d = vectors.shape[-1]
    P = np.zeros((d, d), dtype=np.complex128)

    for v in vectors:
        v -= P @ v
        if L2_norm(v) < tol:
            continue
        else:
            v /= L2_norm(v)
            ortho_vectors.append(v)
            P += projector(v)
            
    return ortho_vectors, P

def orthogonal_complement(vectors, *, tol=1e-8):
    """Return orthogonal vectors spanning the orthogonal complement of the span of the input vectors.
    Input:
        vectors: an (n1, d) matrix of n1 complex vectors of dimension d
        tol: a tolerance for the zero vector
    Output:
        Q: an (n2, d) matrix of n2 orthonormal vectors spanning the orthoganl complement, with d - n1 <= n2 <= d
        P: a (d, d) projector onto the orthogonal complement of the input vectors
    """
    d = np.shape(vectors)[-1]
    I = np.eye(d)
    _, P = gram_schmidt(vectors)
    C = I - P # complement projection
    return gram_schmidt((C@I).T) # this works because the columns of the complement projector span that subspace.

def nullspace(matrix: np.ndarray, *, tol: float=1e-08):
    """Return the nullspace of the matrix.
    Input:
        matrix: an (n, d) matrix of n complex vectors of dimension d
        tol: a tolerance for the zero eigenvalue
    Output:
        Q: an (m, d) matrix containing orthogonal vectors spanning the nullspace (obtained by Gram-Schmidt)
        P: a (d, d) projector onto the span of the nullspace
    """
    return orthogonal_complement(matrix.conj())
