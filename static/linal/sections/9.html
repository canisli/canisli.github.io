9. Finite-State Markov Chains

Represent states with probability/state vectors, whose entries add to 1. A stochastic matrix 𝑃 is a square matrix whose columns are probability vectors. 𝑃 is regular if for all 𝑘, 𝑃𝑘 contains only strictly positive entries.

A Markov Chain refers to the sequence of state vectors, {𝑥𝑘=𝑃𝑘𝑥0, 𝑘∈ℕ}.

  • [Theorem 10] If 𝑃 is a stochastic matrix, then 1 is an eigenvalue of 𝑃.
    • This guarantees existence of steady state vector 𝑞, where 𝑃𝑞=𝑞.
  • [Theorem 11] If 𝑃 is a regular stochastic matrix, then 𝑃 has a unique steady state vector 𝑞, and for any 𝑥0, the Markov Chain {𝑥𝑘} converges to 𝑞 as 𝑥→∞.
