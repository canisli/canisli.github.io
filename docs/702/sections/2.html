2. Ring Theory

2.1. Rings

The integers don’t form a field since division isn’t a closed operation, i.e. multiplicative inverse does not exist. Let’s define a new structure that is almost a field but excludes this requirement.

Definition 6. A commutative ring is a set 𝑅 equipped with addition and multiplication such that
  1. (𝑅,+) is an abelian group.
  2. ×is commutative and associative with multiplicative identity 1
  3. Multiplication distributes over additoin

Examples of rings:

  • Any field 𝔽.
  • ℤ and ℤ/𝑛ℤ
  • ℤ[𝑖]={𝑎+𝑏𝑖|𝑎,𝑏∈ℝ}
  • The polynomial ring 𝑅[𝑥]={𝑎0+𝑎1𝑥+…𝑎𝑛𝑥𝑛|𝑎𝑖∈𝑅}.
  • The zero ring, {0}
  • Product ring 𝑅×𝑅′ (addition and multiplication are defined componentwise).
Definition 7. A ring homomorphism 𝜑:𝑅→𝑅′ preserves addition, multiplication, and the multiplicative identity. Preserving additive identity is implied.

The third condition must be specified since otherwise we are not guaranteed for 𝜑(1)=1 to hold. Consider the zero map which sends all elements to zero in 𝑅′ which is not a homomorphism unless 𝑅′={0}

Examples

  • 𝑅↪︎𝑅[𝑥]3 is an injective ring homomorphism embedding 𝑅 in 𝑅[𝑥].
  • The image 𝜑(𝑅) is a subring of 𝑅′.
  • 𝑅→𝑅×𝑅′ with 𝑟↦(𝑟,0) is not a ring homomorphism since 𝜑(1)=(1,0)≠(1,1). However, 𝑅×𝑅′→𝑅 with (𝑎,𝑏)↦𝑎 is a ring homomorphism.
  • The evaluation map Ev𝑎:𝑅[𝑥]→𝑅, Ev𝑎(𝑓)=𝑓(𝑎) with 𝑎∈𝑅 is a ring homomorphism.
Definition 8. 𝑎∈𝑅 is a unit if there exists 𝑏∈𝑅 such that 𝑎𝑏=𝑏𝑎=1. Let 𝑅× denote the set of units.
Lemma 7.
  1. 𝑎𝑅=𝑅 if and only if 𝑎 is a unit.
  2. The subset 𝑅× of units forms a group under multiplication.
Proof
Suppose 𝑎𝑅=𝑅. Then there exists 𝑏∈𝑅 such that 𝑎𝑏=1, implying 𝑎 is a unit. Suppose 𝑎 is unit. Then 𝑎(𝑎−1𝑏)=𝑏 for all 𝑏∈𝑅. Thus 𝑎𝑅=𝑅.

□

2.2. Ideals

We defined normal subgroups in group theory based on the nice properties of kernels of group homomorphisms. The kernel of a ring homomorphism 𝜑:𝑅→𝑅′ is (1) an additive group and (2) closed under left multiplication by elements of 𝑅.

Definition 9. A subset 𝐼⊂𝑅 is an ideal if it is an additive group closed under multiplication by any element in 𝑅.

The union of ideals is not necessarily an ideal since closure under addition may not hold. For example, consider 𝐼=(2) and 𝐽=(3) as ideals of ℤ. 2+3=5 does not belong to 𝐼∪𝐽 However, we have something weaker for a nested ordered family of ideals.

Lemma 8.
  1. If 𝐴,𝐵 are ideals, then so are the sum of ideals 𝐴+𝐵 and the intersection of ideals 𝐴∩𝐵 (but not necessarily 𝐴∪𝐵).
  2. If 𝐼1⊆𝐼2⊆… is a nested ordered family of ideals or a ring, then their union is an ideal.
  3. The preimage of an ideal is an ideal. The image of an ideal is not necessarily an ideal.

For (3), consider 𝜑:ℤ↪︎ℚ. The image 𝜑(ℤ)=ℤ is not an ideal in ℚ. More generally, If 𝜑:𝑅→𝑅′ is surjective, then 𝜑(𝐼) is an ideal.

Example: 𝑚ℤ∩𝑛ℤ=lcm(𝑚,𝑛)ℤ and 𝑚ℤ+𝑛ℤ=gcd(𝑚,𝑛)ℤ (Bezout’s identity in 18.701)

Denote (𝑎1,…,𝑎𝑘)=𝑅𝑎+⋯+𝑅𝑎𝑘. Note that any ideal containing 𝑎 and 𝑏 contains (𝑎,𝑏). Thus we call (𝑎,𝑏) the minimal ideal generated by the generating set {𝑎,𝑏}.

Definition 10.
  1. An ideal is a principal ideal if there exists a generator 𝑎∈𝑅 such that 𝐼=(𝑎).
  2. A ring is a principal ideal ring (PIR) if all its ideals are principal. A PIR that is an integral domain is a PID.

Example:

  1. 𝑅=(1) generated by any unit.
  2. 5ℤ is a principal ideal in ℤ.
  3. (3,2𝑥+1) is not principle in ℤ[𝑥].
  4. (𝑥2,𝑦)⊂ℤ[𝑥,𝑦] is not principal. This is formaliized through the notion of irreducibility later.
  5. When 𝑛 is not prime, ℤ/𝑛ℤ is a PIR but not a PID.
  6. 𝐹[𝑥]/(𝑥2) is an example of a PIR that is not a PID.

Proposition 3 (Division with remainder in a polynomial ring). Let 𝑅 be a ring and 𝑓∈𝑅[𝑥] be a monic polynomial. Let 𝑔∈𝑅[𝑥]. Then there are polynomials 𝑞,𝑟∈𝑅[𝑥] such that

𝑔(𝑥)=𝑓(𝑥)𝑞(𝑥)+𝑟(𝑥) (24)
with deg(𝑟)<deg(𝑓) or 𝑟=0.

Note that we require the divisor 𝑓(𝑥) to be monic! Otherwise polynomial division might not work (e.g., We cannot divide 𝑥2+1 by 2𝑥 in ℤ[𝑥].)

Proposition 4. Let 𝐹 be a field. Then 𝐹[𝑥] is a PID.
Proof
Choose 𝑓∈𝐼 to be a polynomial of minimal degree. Since 𝐹 is a field, we don’t require 𝑓 to be monic. Invoke division with remainder to show that 𝐼⊂(𝑓).

□

Examples:

  • ℤ is a PID.
  • Let 𝑅=𝐹[𝑥], we have (𝑓)∩(𝑔)=(lcm(𝑓,𝑔)) and (𝑓)+(𝑔)=(gcd(𝑓,𝑔)). This is analogous to ℤ being a PID and our result with 𝑚ℤ and 𝑛ℤ.
  • ℤ[𝑥] is not a PID as Counterexample: 𝐼=(2,𝑥)
  • ℤ[𝑖] is a PID. This can be proved by taking the element of minimal norm and considering division (generalized to Euclidean domains later.).
  • 𝔽[𝑥,𝑦] is not principal. Consider (𝑥,𝑦).

2.3. Quotient Rings

Let 𝐼⊂𝑅 be an ideal. We have an equivalence relation 𝑎∼𝑏⟺𝑎+𝐼=𝑏+𝐼. Let 𝑅/𝐼 denote the set of equivalence classes. Then, it is easy to check that 𝑅/𝐼 forms an ring under (𝑎+𝐼)+(𝑏+𝐼)=(𝑎+𝑏)+𝐼 and (𝑎+𝐼)(𝑏+𝐼)=𝑎𝑏+𝐼.

Theorem 4 (Correspondence Theorem). Suppose 𝜑:𝑅→𝑅′ is a surjective homomorphism with kernel 𝐾 so that 𝑅′≅𝑅/𝐾.
  1. There is a bijective correspondence between ideals of 𝑅 containg 𝐾 and ideals of 𝑅′.
  2. Let 𝐼 be an ideal containing 𝐾. Then 𝑅/𝐼≅𝑅′/𝜑(𝐼)
Proposition 5 (Mapping property). Let 𝜑:𝑅→𝑅′ be a homomorphism, and 𝐼 be an ideal of 𝑅. Let 𝜋:𝑅→𝑅/𝐼 be the canonical map.
  1. There exists a homomorphism 𝜑‾:𝑅/𝐼→𝑅′ such that 𝜑=𝜑‾∘𝜋 if and only if 𝐼⊂ker(𝜑).
  2. If 𝜑 is surjective and 𝐼=ker𝜑, then 𝜑‾ is an isomorphism. (First isomorphism theorem).

For example: ℤ[𝑥]/(𝑥2+1)≅ℤ[𝑖] (consider the evaluation map Ev𝑖)

Suppose 𝐼=(𝑎) is principal, and consider the quotient ring 𝑅‾=𝑅/𝐼. We can think of 𝑅‾ as the ring obtained by imposing the relation 𝑎=0, or “killing” 𝑎. Two elements are in the same coset 𝑏+𝐼 if 𝑥=𝑏+𝑟1𝑎 and 𝑦=𝑏+𝑟2𝑎. Clearly, setting 𝑎=0 enforces 𝑥=𝑦 in 𝑅‾. It also works the other way around. This is known as adding relations.

The Correspondence theorem asserts that killing 𝑎 in 𝑅 and then killing 𝜋(𝑏) in 𝑅‾ yields 𝑅‾/𝑏‾≅𝑅/(𝑎,𝑏), so the order in which we add relations does not matter.

Example 2. Show that the quotient ring 𝑅‾=ℤ[𝑖]/(𝑖−2) is isomorphic to 𝔽5.

Solution. Recall that ℤ[𝑖] is obtained by killing 𝑓(𝑥)=𝑥2+1 in ℤ[𝑥], and the preimage of 𝑖−2 is 𝑔(𝑥)=𝑥−2. Thus 𝑅‾≅ℤ[𝑥]/(𝑓,𝑔). We may introduce the relations in the opposite order, first killing 𝑥−2. This yields ℤ, and the image of 𝑔 is 22+1=5. Thus taking ℤ/(5) yields 𝑅‾≅𝔽5.

2.4. Adjoining Elements

The first isomorphism theorem implies ℤ[𝑥]/(𝑥2−2)≅ℤ[2]. Note that we constructed a new ring ℤ[2] including a base ring ℤ as a subring and a new element 2. Similar thing with generating ℂ≅ℤ[𝑖] from ℤ. This is called a ring extension.

We are interested in generalizing this process, where we construct a new ring from an existing ring 𝑅 and a new element 𝛼. In particular, try 𝑅′=𝑅[𝑥]/𝑓(𝑥) where 𝛼 is a root of 𝑓. [TODO] This works when 𝑓(𝑥) is a monic polynomial and 𝑅 is an integral domain.

Proposition 6 (Adjoining elements). ℤ[𝛼] is defined as the set of polynomials in 𝛼:

ℤ[𝛼]={𝑎0+𝑎1𝛼+𝑎2𝛼2+…+𝑎𝑛𝛼𝑛|𝑎𝑖∈𝑍,𝑛≥0}. (25)
This is generated by powers of 𝛼 with degree less than the minimal polynomial of 𝛼.

A counterexample is if we try constructing 𝑅′=𝑅[𝑥]/𝑓(𝑥) where 𝑅=ℤ/6ℤ and 𝑓(𝑥)=3𝑥−1. Imposing 3𝑥−1=0 implies 3𝑥=1. Multiplying both sides implies 0=2 in ℤ/6ℤ, yielding a contradiction.

Definition 11. 𝑎∈𝑅{0} is a zero divider if there exists 𝑏≠0 such that 𝑎𝑏=0.

A ring with no zero divisors is an integral domain.

For example, 2⋅3=0 in ℤ6, making 2 and 3 zero dividers. ℤ and ℤ𝑝 for prime 𝑝 are integral domains

Proposition 7 (Cancellation law). If 𝑅 is an integral domain and 𝑎∈𝑅−{0}, 𝑎𝑏=𝑎𝑐 implies 𝑏=𝑐.
Proof
𝑎𝑏=𝑎𝑐 implies 𝑎(𝑏−𝑐)=0, implying 𝑏−𝑐=0 since 𝑎 has no zero divisors.

Proposition 8.
  1. 𝑃⊊ is prime if and only if for ideals 𝐴,𝐵 of 𝑅, 𝐴𝐵⊂𝑃 implies either 𝐴⊂𝑃 or 𝐵⊂𝑃.
  2. 𝑃⊊𝑅 is prime if and only if 𝑅‾=𝑅/𝑃 is an integral domain.
Proof

  1. Forward proof: If 𝐵⊂𝑃 we are done. Otherwise take 𝑏∈𝐵 that is not in 𝑃. Then 𝐴𝑏⊂𝑃 by hypothesis. Then by the primality of 𝑃, we must have 𝐴⊂𝑃.

    Backward proof: Suppose 𝑎𝑏∈𝑃. Let 𝐴=(𝑎) and 𝐵=(𝑏). We have 𝐴𝐵=(𝑎𝑏)⊂𝑃. Hence 𝑎∈𝑃 or 𝑏∈𝑃.

  2. Follow the definition of integral domain. The backward proof is easier.

□

2.6. Maximal Ideals

Definition 13. A proper ideal 𝑀⊊𝑅 is maximal satisfying the following condition: if 𝑀′ is another ideal with 𝑀⊂𝑀′, then either 𝑀′=𝑀 or 𝑀′=𝑅.
Proposition 10.
  1. 𝑀⊊𝑅 is maximal if and only if 𝑎∈𝑅\𝑀 implies 𝑅=𝑎𝑅+𝑀.
  2. A maximal ideal is prime.
  3. 𝑀⊊𝑅 is maximal if and only if 𝑅‾=𝑅/𝑀 is a field.
Proof

  1. Follows from the definition and the fact that the sum of two ideals is an ideal.

  2. Suppose 𝑎𝑏∈𝑀 and 𝑎∉𝑀. Then 𝑎𝑅+𝑀=𝑅 from (1). Then 𝑏𝑅=𝑎𝑏𝑅+𝑏𝑀=𝑀, implying that 𝑏∈𝑀. Thus 𝑀 is prime.

  3. Forward proof. Suppose 𝑎∉𝑀. Then by (1) 𝑎𝑅+𝑀=𝑅 so there exists 𝑏∈𝑅,𝑚∈𝑀 such that 𝑎𝑏+𝑚=1𝑅, implying that 𝑎‾𝑏‾=1‾. Thus every nonzero element in 𝑅/𝑀 has a multiplicative inverse. The rest of the field definitions are satisfied since 𝑅/𝑀 is a ring.

    Backward proof. Suppose 𝑅/𝑀 is a field. Consider 𝑎≠𝑀. Then there exists a multiplicative inverse 𝑏‾ such that 𝑎‾𝑏‾=1‾. This implies 𝑎𝑏+𝑀=1+𝑀, i.e. some 𝑎𝑏+𝑚=1, implying that 1∈𝑎𝑅+𝑀. Thus 𝑎𝑅+𝑀=𝑅. Invoke (1).

□

Examples

  • In ℤ, prime ideals are also maximal.
  • (𝑥2+1)⊂ℚ[𝑥] is maximal, since ℚ[𝑥]/(𝑥2+1)≅ℚ[𝑖] is a field.
  • (𝑥)⊂ℤ[𝑥] is not maximal since ℤ is not a field.
Proposition 11 (Prime ⟺ Maximal in a PID). If 𝑅 is a PID, then nonzero prime ideals are also maximal. I.e. 𝐼 is prime if and only if only 𝐼 is maximal.
Proof

Suppose 𝑎 is prime, and (𝑎)⊊𝐼⊊𝑅. Then 𝐼=(𝑏) must satisfy 𝑏 divides 𝑎. But in PIDs, prime elements are irreducible, so we must have 𝑏∈𝑅×, implying that 𝐼 is maximal.

This proof doesn’t work for the zero ring.

□

To summarize, in a PID the following statements are equivalent:

  1. 𝑎∈𝑅 is prime.
  2. 𝑎 is irreducibility.
  3. (𝑎) is maximal.
Lemma 9 (Sufficient conditions for a ring to be a field).
  1. An integral domain with finite cardinality is a field.
  2. A ring 𝑅 is a field if and only if it contains no proper nontrivial ideals. That is, it has two ideals, the zero ideal and the unit ideal (𝑅 itself).
Proof

  1. Look at left multiplication and argue each element has a multiplicative inverse.
  2. (⟹) Let 𝐼 be a nontrivial ideal, and let 𝑎∈𝐼−{0}. Then 𝑎𝑎−1=1∈𝐼, so 𝐼 is the unit ideal.
    (⟸) It suffices to show that all nonzero elements in 𝑅 are units. For all 𝑎≠0, by hypothesis we have 𝑎𝑅=𝑅, thus 𝑎 is a unit.

□

Corollary. Let 𝐹 be a field. Then every homomorphism 𝜑:𝐹→𝑅 to a nonzero ring is injective. 𝜑(1𝐹)=1𝑅, so the kernel does not include 1𝐹. Thus it must be the zero ideal.
