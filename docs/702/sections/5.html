5.1. Modules

The analog for a ring 𝑅 for a vector space over a field is called a module.

Definition 29. Let 𝑅 be a ring. An 𝑹-module 𝑉 is an abelian group with addition (+) and scalar multiple 𝑅×𝑉→𝑉 defined such that for all 𝑟,𝑠∈𝑅 and 𝑣,𝑣′∈𝑉
  1. 1𝑣=𝑣
  2. (𝑟𝑠)𝑣=𝑟(𝑠𝑣)
  3. (𝑟+𝑠)𝑣=𝑟𝑣+𝑠𝑣
  4. 𝑟(𝑣+𝑣′)=𝑟𝑣+𝑟𝑣′

These are the same as the axioms for a vector space (for a more comprehensive definition, see Definition 54). The fact that a ring lacks multiplicative invertibility makes modules more complicated. For example, not every module has a basis.

Note. For finite rings, direct sum and direct product are the same thing. It does not hold for infinite.

Examples.

  1. Let 𝐼⊆𝑅 be an ideal. Then 𝐼 and 𝑅/𝐼 are 𝑅-modules.
  3. Free module 𝑅𝑛 of 𝑅-vectors, column vectors with entries in 𝑅.
  4. ℤ/11ℤ⊕ℤ/23ℤ is a ℤ-module.
  5. Let 𝑅=𝐹[𝑥] be the right of polynomials over a field 𝐹. Let 𝑀 be an 𝑅-module. Then, 𝑀 can be seen as an 𝐹-vector space and scalar multiplication by 𝑥 is a linear operator on 𝑉. More generally, we have the following proposition:
Proposition 32. 𝐹[𝑥] modules correspond to 𝐹-vector spaces with a chosen linear operator.

This is subtle. We have two notions of modulues here. If 𝑥1,𝑥2,…,𝑥𝑛∈𝐹[𝑥] generate 𝑀, i.e. 𝑀={𝑎1𝑥1+…𝑎𝑛𝑥𝑛,𝑎𝑖∈𝐹[𝑥]}, we also have {𝑥𝑖} generates an 𝐹-vector space 𝑉={𝑎1𝑥1+…𝑎𝑛𝑥𝑛,𝑎𝑖∈𝐹}, which with the linear operator defines 𝑀

Proposition 33. Abelian group and ℤ-module are equivalent concepts.
Proof
If we start with a ℤ-module, we can forget about scalar multiplication to get an abelian group under addition. Starting with an abelian group under addition, we can define scalar multiplication as repeated addition to get a ℤ-module.

5.2. Free Modules

Definition 31. A basis for an 𝑅-module 𝑀 is a set {𝑣1,…,𝑣𝑛} that generates 𝑉 and is linearly independent with respect to linear combinations over 𝑅.

Examples:

  1. Any finite-dimensional complex vector spaces has a basis.
  2. 𝑍/6ℤ as a module over ℤ is generated by {1} but 0=6⋅1. It does not have a basis.
  3. If 𝑆⊂𝑀 generates 𝑀 and |𝑆|=𝑛, then we have a surjective homomorphism 𝜙:𝑅𝑛→𝑀 with 𝑀≅𝑅𝑛/ker𝜙.
Definition 32.
  1. An 𝑅-module 𝑀 is a free module if 𝑀≅𝑅𝑛.
  2. A 𝑍-module 𝑀 is a free abelian group if 𝑀≅ℤ𝑛.
Proposition 34. A module is free if and only if it has a basis.

Follows immediately from the definition of a basis.

  2. Scalar multiplication of rows by units (±1∈ℤ)
  3. Add scalar multiplication of 1 row to another row.
Proposition 36. 𝐴 is invertible in 𝑅 if and only if det𝐴 is a unit in that ring.
Proof

5.4. Noetherian Rings

Definition 33.
  1. An 𝑅-module 𝑀 is finitely generated if there exists a finite set 𝐵={𝑣1,…,𝑣𝑛} such that any 𝑣∈𝑀 can be expressed as a linearly combination in 𝐵.
  2. 𝑀 is finitely-presented if …

Motivation: A finitely-generated module is not necessarily finitely-presented. We want to classify the types of rings whose modules imply this.

Definition 34. A ring 𝑅 is Noetherian if every ideal of 𝑅 is finitely generated.

Examples:

  • Any PID, e.g. ℤ and 𝔽[𝑥], is Noetherian since every ideal is generated by one element (PID property).
  • 𝔽[𝑥1,…,𝑥𝑛] turns out to be Noetherian by the Hilbert basis theorem.
  • 𝔽[𝑥1,𝑥2,⋯] is not Noetherian. Consider the ideal of polynomials with no constant term.

Proof
Obvious.
