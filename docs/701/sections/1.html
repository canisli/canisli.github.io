1. Groups

1.1. Motivation and definition

  • Groups are used to describe symmetry and transformations.
  • Def Let 𝑋 be a set. Define Perm(𝑋) as the set of bijective maps 𝑓:𝑋→𝑋.
  • A group of transformations of 𝑋 is a subset 𝐺⊂Perm(𝑋) satisfying the following relations:
    1. Closure: 𝑓,𝑔∈𝐺⟹𝑓∘𝑔∈𝐺.
    2. Identity: 𝐼∈𝐺 where 𝐼:𝑋→𝑋.
    3. Inverse : 𝑓∈𝐺⟹𝑓−1∈𝐺.
    • Examples
      1. 𝑋=arbitrary set,𝐺=Perm(𝑋).
      2. 𝑋=arbitrary set,𝐺={𝐼}.
      3. 𝑋=ℝ𝑛,𝐺=Aut(ℝ𝑛), the set of invertible linear operators.
      4. 𝑋={1,…,𝑛},𝐺=𝐶𝑛, the set of rotational symmetries of an 𝑛-gon.
      5. 𝑋={1,…,𝑛},𝐺=𝐷𝑛, (Dihedral group) the set of all symmetries (rotations and reflections) of an 𝑛-gon.
        • There are 𝑛 of both, making this an order 2𝑛 group.
      6. 𝑋=ℝ𝑛,𝐺= group of distance preserving operators (isometries).
    • Many group of transformations come from taking transformations that preserve symmetry, e.g. linearity, structure of polygon, and distance.

  • Perm{1,…,𝑛} is called the symmetric group 𝑆𝑛. We express 𝑆∈𝑆𝑛 as

    𝑆=(12…𝑛𝑆(1)𝑆(2)…𝑆(𝑛)) (1)
    • We can take the cycle decomposition of 𝑆.

    • Example:

      (123213)∘(123132)=(123231)(123132)∘(123213)=(123312). (2)
      Beware of the indices vs values!
  • A group is a set 𝐺 equipped with a multiplication 𝑚:𝐺×𝐺→𝐺 satisfying the following relations
    1. Associativity: a(b c) = (a b) c.
    2. Identity: ∃𝑒∈𝐺s.t.𝑎𝑒=𝑒𝑎=𝑎
    3. Inverse: ∃𝑎−1∈𝐺s.t.𝑎𝑎−1=𝑎−1𝑎=𝑒.
    • A pair (𝐺,𝑚) only satisfying 1 or 1&2 is called a semigroup or monoid resp.
    • Examples
      1. 𝐺=any group of transformations,𝑚=function composition.
      2. 𝐺=numerical group(ℤ⊂ℚ⊂ℝ⊂ℂ),𝑚=addition.
      3. 𝐺=ℚ/ℝ/ℂ−{0},𝑚=multiplication.
      4. 𝐺=GL𝑛(ℝ),𝑚=matrix multiplication
      5. Multiplicative group of integers modulo n: Set consists of integers relatively prime to 𝑛. And is generated by the primitive roots of 𝑛.
    • Define the order of 𝐺 as the size of it’s set |𝐺|. Define the order of an element 𝑔∈𝐺 as the order of the subgroup it generates, i.e. the lowest 𝑚 such that 𝑔𝑚=1. If no such 𝑚 exists, then we have 𝑚=∞.
    • 𝐺 is called abelian if 𝑚 is commutative.
      • Examples: numerical group, 𝑆𝑛for𝑛≤2
      • Nonexamples: 𝐷𝑛,𝑆𝑛for𝑛≥3,GL𝑛(ℝ)for𝑛≥1
    • Example of a subgroup: SL𝑛(ℝ)⊂GL𝑛(ℝ)
  • Let 𝑆⊂𝐺 be a subset of 𝐺, not necessarily a subgroup. Let ⟨𝑆⟩ be the set of all elements in the form ∏𝑛𝑆𝑖±1 where 𝑛 is a whole number and 𝑆𝑖∈𝑆 is not necessarily unique. Note 𝑒∈⟨𝑆⟩ corresponds to 𝑛=0.
    • We say that ⟨𝑆⟩ is a subgroup generated by the subset 𝑆.
    • Example: 𝑆𝑛 is generated by {(1,2),(2,3),…,(𝑛−1,𝑛)}, the set of transpositions of neighbors
    • 𝐺 is cyclic if it is generated by one element.
      • Example: 𝐶𝑛 is generated by a rotation of 2𝜋/𝑛.
    • Prop. Let 𝐺=⟨𝑔⟩ be a cyclic group. If |𝐺|=∞, then for all 𝑖,𝑗∈ℤ, 𝑖≠𝑗⟺𝑔𝑖≠𝑔𝑗. If 𝐺 is finite, there exists 𝑛∈ℤ>0 such that 𝑔𝑛=𝑒, and 𝐺={𝑒,𝑔,…,𝑔𝑛−1} and 𝑔𝑖𝑔𝑗=𝑔𝑖+𝑗mod𝑛.
    Proof. For the finite case, such 𝑛 must exist by pigeonhole. Choose the smallest one. For the infinite case, prove it by contradiction.
  • Prop. Suppose 𝑥 has order 𝑛. The order of 𝑥𝑘 is 𝑛/gcd(𝑘,𝑛)
  • Prop Suppose 𝐻 and 𝐾 are two subgroups of 𝐺.
    1. 𝐻∩𝐾 is a subgroup of 𝐺.
    2. 𝐻∪𝐾 is a subgroup if and only if 𝐻=𝐺 or 𝐾=𝐺.

1.2. Subgroups of (ℤ,+)

  • Thm 1. Subgroups of (ℤ,+) are {0} and 𝑑ℤ where 𝑑∈ℤ+.

Proof. Suppose 𝐻 is a subgroup of ℤ. Take 𝑑∈𝐻 to be the smallest positive integer in 𝐻. We then have that 𝐻⊃𝑑ℤ. Now take positive 𝑛∈𝐻. By division, 𝑛=𝑞𝑑+𝑟 where 0≤𝑟≤𝑑. By hypothesis, 𝑑 was the smallest positive element, so 𝑟 must equal zero. Thus 𝑛∈𝑑ℤ and 𝐻⊂𝑑ℤ. Thus 𝐻=𝑑ℤ. □

  • Prop. Suppose 𝑎,𝑏∈ℤ and let 𝐻=⟨{𝑎,𝑏}⟩. Then 𝐻=𝑑ℤ where 𝑑=gcd(𝑎,𝑏).

Proof. By Theorem 1, 𝐻 can be expressed in the form 𝑚ℤ for some positive integer 𝑚. Then we must have that 𝑚 is a common disivor of both 𝑎 and 𝑏. Thus 𝑚≤𝑑. Since 𝑚∈𝐻, we must have 𝑚=𝑟𝑎+𝑠𝑏 for integers 𝑟 and 𝑠. The RHS is a positive multiple of 𝑑, implying 𝑚≥𝑑. Thus 𝑑 must equal 𝑚. □

  • Cor (Bezout’s lemma): Let a and b be integers with GCD d. Then there exist integers 𝑥 and 𝑦 such that 𝑎𝑥+𝑏𝑦=𝑑.

1.3. Homomorphisms

  • Def. Let 𝐺 and 𝐺′ be groups. A homomorphism is a map from 𝐺 to 𝐺′ such that for all 𝑎,𝑏∈𝐺,

    𝜑(𝑎𝑏)=𝜑(𝑎)𝜑(𝑏). (3)
    • Examples:
      1. 𝜑:ℤ+→ℤ+,𝜑(𝑥)=𝑛𝑥
      2. 𝜑:GL𝑛(ℝ+)→ℝ,𝜑(𝐴)=det𝐴
      3. 𝜑:ℤ→𝐺,𝜑𝑔(𝑛)=𝑔𝑛
      4. 𝜑:(ℝ,+)→(ℝ>0,×),𝜑=exp
      5. 𝜌:𝑆𝑛→GL𝑛(ℝ) (permutation matrix)
      6. Conjugation: 𝑓𝑔(𝑥)=𝑔𝑥𝑔−1
      7. Composition of homomorphisms, e.g. sign.
    • Prop. 𝜑(1)=1 (identity) and 𝜑(𝑎−1)=[𝜑(𝑎)]−1 (inverse)
    • Prop. The image and kernel of 𝜑 are both subgroups.
  • Def. If 𝐻 is a subgroup of 𝐺 and 𝑎∈𝐺, the set 𝑎𝐻={𝑎ℎ:ℎ∈𝐻}⊂𝐺 is called a left coset of 𝐻 in 𝐺.
  • Def. Suppose 𝑎,𝑔∈𝐺. Conjugate of 𝑎 by 𝑔 is the element 𝑔𝑎𝑔−1. A subgroup 𝑁 of 𝐺 is a normal subgroup if for every 𝑎∈𝑁 and 𝑔∈𝐺, 𝑔𝑎𝑔−1∈𝑁.
    • Prop. The kernel of 𝜑 is normal.
  • Def. The center 𝑍 of a group 𝐺 is the set of elements that commute with every element of 𝐺.
    • Prop. 𝑍 is a normal subgroup.

1.5. Inversions and Game of 15

  • Sign of a permutation is a homomorphism: sign:𝑆𝑛→{±1} is the determinant of its permutation matrix. Thus, sign(𝑠)=(−1)𝑚 where 𝑚 is the number of transpositions in some representation 𝑠=𝑡1…𝑡𝑚.
    • 𝑠 is an even permutation if sign(𝑠)=1.
    • Let 𝑠∈𝑆𝑁. An inversion is a pair 1≤𝑖<𝑗≤𝑛 such that 𝑠(𝑖)>𝑠(𝑗). This is counted by inv(𝑠)

    • Prop. Suppose 𝑠∈𝑆𝑛 and 𝑠𝑖=(𝑖,𝑖+1). Then

      inv(𝑠∘𝑠𝑖)={inv(𝑠)+1if𝑠(𝑖)<𝑠(𝑖+1)inv(𝑠)−1if𝑠(𝑖)>𝑠(𝑖+1) (4)

    • Cor. Every permutation is expressed as at least inv(𝑠) transpositions of neighbors. And

      sign(𝑠)=(−1)inv(𝑠). (5)
  • Prop. The alternating group 𝐴𝑛 is generated by 3-cycles.
    • Prop. There is no subgroup of 𝐴𝑛 with order |𝐴𝑛|/2. Every subgroup of index 2 is normal. Since all the 3-cycles would be mapped to identity, contradicting Theorem 2.12.2
  • Prop. An 𝑛-cycle can be expressed 𝑛−1 transpositions of neighbors: (1234)=(12)(23)(34). Thus the sign is (−1)𝑛−1
  • Game of 15: Invariant is sign of permutation times (−1)𝑛 where 𝑛 is the row number. (Horizontal moves obviously don’t change it. Vertical moves adds 4-cycle which is odd)
    Exercise: Prove for an 𝑚x𝑛 board for 𝑚≥2 and 𝑛≥3 that any two positions of the same sign can always be reached from each other. Hint: Do 2x3 case by hand and then use induction.

1.6. Cosets

  • Def A partition ∏ of a set 𝑆 is a subdivision of 𝑆 into disjoint nonempty subsets.
  • Def An equivalence relation is a binary relation is transitive, symmetric, and reflexive.
    • Examples:
      1. Cosets (𝑎∼𝑏 if 𝑎=𝑏ℎ for some ℎ∈𝐻⊂𝐺)
      2. Conjugacy (𝑎∼𝑏 if 𝑔𝑎=𝑏𝑔 for some 𝑔∈𝐺)
      3. Equivalence relation defined by a map: 𝑎∼𝑏⟺𝑓(𝑎)=𝑓(𝑏)
  • Let 𝜋:𝑆→𝑆‾ be the surjective map that maps 𝑎∈𝑆 to its equivalence class, denoted 𝐶𝑎 or 𝑎‾.
  • Define the fiber of an element under a function 𝑓 as its preimage.
    • Prop. Let 𝐾 be the kernel of a homomorphsim 𝜑:𝐺→𝐺′. Then the fiber of 𝜑 that contains 𝑎 is the coset 𝑎𝐾.
  • Prop. The left cosets of a subgroup 𝐻⊂𝐺 partition 𝐺.
    • The equivalence relation for left cosets is 𝑎∼𝑏 if 𝑎=𝑏ℎ for some ℎ∈𝐻.
  • Lem. All left cosets 𝑎𝐻 have the same order.

  • Thm. (Lagrange) Let the index of a subgroup [𝐺:𝐻] be the number of left cosets. Then

    |𝐺|=|𝐻|[𝐺:𝐻] (6)
    • Cor. The order of an element of a finite group divides the order of the group.
    • Cor. Groups of prime order are cyclic.
    • Example: |𝐺|=|ker𝜑|⋅|im𝜑|
  • Left and right cosets aren’t necessarily the same.
    • Prop. If 𝐻 is normal then the left and right cosets are equal.
    • Prop. The number of left and right cosets are equal
      Proof. 𝐻 is a left and right coset. Since all left and right cosets have order equal to |𝐻|, by Lagrange’s theorem there must be the same number of left and right cosets.
    • Prop. If the left and right cosets are the same, then they are necessarily in the form 𝑔𝐻 and 𝐻𝑔 for some 𝑔.
      Proof. Suppose the left coset is 𝑔𝐻. This contains 𝑔. Since the right cosets are disjoint, the only right coset that contains this is 𝐻𝑔.
  • Thm. Correspondence theorem: Suppose 𝜑:𝐺→𝐺′ is a surjective homomorphism. There is a bijective mapping between subgroups of 𝐺 containing the kernel of 𝜑 and subgroups in 𝐺′.

1.7. Structure of groups

  1. Groups of prime order 𝑝 are cyclic.

  2. Groups of order 𝑝𝑞 where 𝑝 and 𝑞 are relatively prime integers are isomorphic to product of ℤ𝑝 and ℤ𝑞.

    • Proved later with Sylow theorem
    • Example ℤ6≃ℤ2×ℤ3. This is exactly the Chinese remainder theorem. An isomorphism is
    𝜑(𝑛)=(𝑛mod2,𝑛mod3) (7)
  3. Structure of group of order 4 is either isomorphic to ℤ4 or the Klein four group ℤ2×ℤ2.

1.8. Quotient Groups

  • Alternate definition of normal subgroup; left cosets equal right cosets
    • Examples:
      1. 𝐴𝑛 is normal in 𝑆𝑛 for all 𝑛≥3.
        • This is because kernel of sign homomorphism is precisely 𝐴𝑛 and see example 3.
      2. Prop. Every subgroup of index 2 is normal.
        Proof. https://proofwiki.org/wiki/Subgroup_of_Index_2_is_Normal
      3. Prop. Kernel of any homomorphism is normal.
      4. Prop. Center of 𝐺 is a normal subgroup
      5. Exercise: Let ISO+(ℝ2) be the group of motions (distance preserving transformations of ℝ2 consisting of translations and rotations about any point. Let 𝑇 be the subgroup of translations and 𝑅 be the subgroup of rotations about the origin. Then 𝑇 is normal but 𝑅 is not normal.)
  • Normal subgroups are important because their cosets combine nicely and allow us to define quotient groups.
    • Let 𝑆 be the set of cosets of normal subgroup 𝐻.
    • Prop. If 𝐻 is normal, the product set (𝑎𝐻)(𝑏𝐻) equals 𝑎𝑏𝐻.
    • Prop. 𝑆 equipped with the law of composition (𝑎𝐻)(𝑏𝐻)=𝑎𝑏𝐻 forms a group.
      • Def. Let the quotient group be the set of cosets 𝑆=𝐺‾=𝐺/𝐻 equipped with such composition.
    • Thm. For normal 𝐻, 𝜋:𝐺→𝐺/𝐻 given by 𝜋(𝑎)=𝑎𝐻 is a surjective homomorphism whose kernel is 𝐻. This is called the canonical map from 𝐺 to 𝐺/𝐻.
      • Prop. ker𝜑=𝐻.
      • Cor. Every normal subgroup is the kernel of a surjective homomorphism.
    • Exercise: Show that if 𝐻 is not normal, then there is no group structure on 𝑆 such that 𝜑 defined above is a homomorphism.
      • For example, it is easy to verify that 𝐻=⟨(12)⟩⊂𝑆3 is not normal. There is no group structure in the set of left cosets with a surjective homomorphism 𝐺→𝐺/𝐻. Indeed, |𝐺/𝐻|=3, so if it is given a group structure it will be a group ℤ3. But any homomorphism 𝑆𝑛→ℤ3 is trivial (maps to 0) since 𝑆𝑛 is generated by elements of order 2 and every non-identity element in ℤ3 has order 3 (write out homomorphism).
    • Examples of quotient groups
      1. 𝑆𝑛/𝐴𝑛≃ℤ2 (recall structure of groups of prime order)
      2. (𝐺1×𝐺2)/𝐺1≃𝐺2
        • I think more accurate notation is (G_1, e_2)?
        • Made obvious by first isomorphis theorem. Let 𝑓((𝑔1,𝑔2))=𝑔1
      3. ℤ4/ℤ2≃ℤ2 but ℤ4≄ℤ2×ℤ2
        • The first ℤ2 refers to the subgroup {0,2} which has order 2 and is isomorphic to ℤ2.
      4. ℤ/𝑛ℤ≃ℤ𝑛 (modular arithmetic.)
    • Thm. First Isomorphism theorem: Let 𝜑:𝐺→𝐺′ have kernel 𝑁. Then 𝐺/𝑁 is isomorphic to im𝜑. The isomorphism is 𝜑‾=𝜑(𝑎) where 𝑎 is any element in the coset.

1.10. Direct product and Product of subgroups

  • Def The operator × is called the direct product. It creates a new group 𝐻×𝐾 from 𝐻 and 𝐾.
  • Def Suppose 𝐻 and 𝐾 are subgroups of 𝐺. Define 𝑓:𝐻×𝐾→𝐺 as the map defined by 𝑓(ℎ,𝑘)=ℎ𝑘 and define the product of 𝐻 and 𝐾 as 𝐻𝐾≝img𝑓
  • Prop
    1. 𝑓 is injective if and only if 𝐻∩𝐾={𝑒}.
    2. 𝑓 is a homomorphism if and only if 𝐻 and 𝐾 commute.
    3. If 𝐻 or 𝐾 is a normal subgroup, then 𝐻𝐾 is a subgroup of 𝐺.
    4. 𝑓 is an isomorphism if and only if 𝐻𝐾=𝐺,𝐻∩𝐾={𝑒}, and 𝐻,𝐾 are normal.
    5. If 𝑓 is injective and 𝐻𝐾=𝐺, then there exists a bijection between 𝐻×𝐾 and 𝐺.
