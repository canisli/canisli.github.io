3. Policy gradient methods

For convergence, we consider either finite-horizon undiscounted return or infinite-horizon discounted return.

A policy induces a distribution over entire trajectories:

𝜏=(𝑠0,𝑎0,𝑠1,𝑎1,…)𝑝𝜋(𝜏)=𝜌0(𝑠0)∏𝑡𝜋(𝑎𝑡|𝑠𝑡)𝑃(𝑠𝑡+1|𝑠𝑡,𝑎𝑡) (6)

The objective is

𝐽(𝜃)=𝔼𝜏∼𝜋𝜃[𝑅(𝜏)] (7)

We will construct a surrogate objective whose gradient equals the policy gradient, i.e. the gradient of 𝐽(𝜃)=𝔼𝜏∼𝜋𝜃[𝑅(𝜏)].

Theorem 2 (Policy Gradient Theorem).

∇𝜃𝐽(𝜃)=𝔼𝜏∼𝜋𝜃[∑𝑡=0𝑇∇𝜃log𝜋𝜃(𝑎𝑡|𝑠𝑡)Φ𝑡] (11)

for any Φ𝑡 satisfying 𝔼[Φ𝑡|𝑠𝑡,𝑎𝑡]=𝑄𝜋(𝑠𝑡,𝑎𝑡) For example:

Proof

Let 𝐺𝑡 be the returns to go from time 𝑡.

𝐽(𝜃)=𝔼𝜏∼𝜋𝑅(𝜏)⟹∇𝐽=𝔼[∇log𝜋(𝜏)𝑅(𝜏)]=𝔼𝜏∼𝜋[∑𝑡=1𝑇∇log(𝜋(𝑎𝑡|𝑠𝑡))𝑅(𝜏)]=𝔼𝜏∼𝜋[∑𝑡=1𝑇∇log(𝜋(𝑎𝑡|𝑠𝑡))𝐺𝑡]=∑𝑡=1𝑇𝔼[𝔼[∇log(𝜋(𝑎𝑡|𝑠𝑡))𝐺𝑡]|𝑠𝑡,𝑎𝑡]=∑𝑡=1𝑇𝔼[∇log(𝜋(𝑎𝑡|𝑠𝑡))𝔼[𝐺𝑡|𝑠𝑡,𝑎𝑡]]=∑𝑡=1𝑇𝔼[∇log(𝜋(𝑎𝑡|𝑠𝑡))𝑄𝜋(𝑠𝑡,𝑎𝑡)] (12)
since 𝑄𝜋(𝑠𝑡,𝑎𝑡)≔𝔼[𝐺𝑡|𝑠𝑡,𝑎𝑡]. The same tower law step applies for any 𝔼[Φ𝑡|𝑠𝑡,𝑎𝑡]=𝑄𝜋(𝑠𝑡,𝑎𝑡).

□

To Monte Carlo estimate the gradient, we can gradient descent on the loss function (treating the rewards as constants)

ℒ︀=−1|𝐷|∑𝜏∈𝐷∑𝑡=0𝑇log𝜋𝜃(𝑎𝑡|𝑠𝑡)Φ𝑡 (13)

Warning: ℒ︀ has the same gradient as −𝐽(𝜃) but cannot be interpretted as expected return.

Empirically, setting Φ𝑡 to the reward-to-go function ∑𝑡′=𝑡𝑇𝑟𝑡′ reduces variance compared to if we used the total reward. Intuitively, we don’t want early actions to get rewearded for things from much later, or late actions to get credit for earlier rewards. This is exactly what REINFORCE, the original Monte Carlo policy-gradient algorithm from 1992, does.

REINFORCE
  1. Sample episodes and store transition
  2. For each episode 𝜏
    1. For each timestep 𝑡,

      1. Compute the reward-to-go

        𝐺𝑡=∑𝑡′=𝑡𝑇𝛾𝑡′−𝑡𝑟𝑡 (14)
      2. Update 𝜃←𝜃+𝛼∇𝜃log𝜋𝜃(𝑎𝑡|𝑠𝑡)𝐺𝑡

Remark. During training we sample moves according to the policy. During evaluation it is standard to greedy sample instead of sampling stochastically.

3.2.1. Notes on implementation

  • The rewards should be treated as constant and not differentiable (the environment is not differentiable). Use torch.stack() to accumulate the log probabilities while retaining requires_grad=True.

  • For sampling from the policy, use

    dist = Categorical(logits=logits)
logp = dist.log_prob(a)

    Reasoning: PyTorch computes log_softmax internally in a stable way. You avoid forming tiny probabilities explicitly. This is the standard trick in classification too.

  • To reduce the variance, subtract the returns to go from their mean. If we don’t do this, then all gradients push probabilities up since all 𝐺𝑡 are positive. Instead we want to estimate advantages:

    def train(self, optimizer: torch.optim.Optimizer,
            num_episodes=10, T=100, γ=0.99):
    model = self.model

    model.train()
    for _ in tqdm(range(num_episodes)):
        loss = 0.0
        moves, rewards, logps, _ = self.run_episode(T)
        
        # Returns to go
        returns = []
        for t in range(T):
            G_t = 0.0
            for k in range(T - t):
                G_t += (γ ** k) * rewards[t + k]
            returns.append(G_t)
        returns = torch.tensor(returns, dtype=torch.float32)
        
        # REINFORCE loss
        loss = - (logps * (returns-returns.mean())).mean()

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
  • Normalize inputs to −1 and 1. I was passing in the x, y position on the board, but I should divide by the half-width.
  • Returns to go: Mathematically the returns should be counted from the beginning of the episode, not 𝑡. I.e. ∑𝑡′=𝑡𝑘𝛾𝑡′𝑟𝑡′=𝛾𝑡𝐺𝑡 instead of 𝐺𝑡=∑𝑡′=𝑡𝑘𝛾𝑡′−𝑡𝑟𝑡′. REINFORCE drops the extra 𝛾𝑡 factor anyway. Intuitively this prevents the algorithm from focusing on early decisions, and empirically it works out to be a feature not a bug.

Let’s introduce a baseline, so that Φ𝑡=𝐺𝑡−𝑏(𝑠𝑡) where 𝐺𝑡 is the reward-to-go and 𝑏(𝑠𝑡)=𝑉𝜋(𝑠𝑡) is the state-value function. The actor is training 𝜃 and the critic parameterizes the state-value function as 𝑉𝜙

Denote Φ𝑡=𝐴̂𝑡 as the advantage at time 𝑡.

𝐴̂𝑡=𝛿𝑡≔𝑟𝑡+𝛾𝑉𝜙(𝑠𝑡+1)−𝑉𝜙(𝑠𝑡) (15)

The critic trains 𝑉𝜙 to satisfy the Bellman equation for state-value functions:

𝑉𝜋(𝑠𝑡)≈𝑟𝑡+𝛾𝑉𝜋(𝑠𝑡+1)⟹ℒ︀critic(𝜙)=𝔼[𝛿𝑡2] (16)

Vanilla actor–critic update loop

  1. Sample 𝑎𝑡∼𝜋𝜃(⋅|𝑠𝑡)
  2. Observe 𝑟𝑡,𝑠𝑡+1

  3. Compute TD error

    𝛿𝑡=(𝑟𝑡+𝛾stopgrad(𝑉𝜙(𝑠𝑡+1)))−𝑉𝜙(𝑠𝑡) (17)
  4. Actor update: 𝜃←𝜃+𝛼∇𝜃log𝜋𝜃(𝑎𝑡|𝑠𝑡)𝛿𝑡
  5. Critic update: 𝜙←𝜙−𝛽∇𝜙𝛿𝑡2.

Note 𝑉𝜙(𝑠𝑡+1) must be treated as a constant, so we use “stopgrad” above.

This lowers variance but introduces bias since 𝑉𝜙 is approximate and trained via bootstrapping (using your own current estimate to define the learning target).

Note. Both REINFORCE and Actor-critic are on-policy. Q-learning is off-policy.

Note. Actor–critic directly solves the infinite-horizon problem. You can train for time 𝑇 and write your reward as the first 𝑇 rewards plus the discounted value function of the terminal state.
