14. Streaming Algorithms

Streaming algorithms can be thought of “sublinear space” algorithms. They can be more powerful than sublinear time:

  • For example, you can compute the maximum of an array in 𝑂(1) space yet 𝑂(𝑛) time. On the other hand, 𝑂(𝑇) algorithms can only ever use 𝑂(𝑇) space.
  • Also, sublinear space algorithms need not rely on randomization/approximation, but usually they do.
