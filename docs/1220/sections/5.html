5. Competitive Analysis

To analyze the quality of an algorithm, sometimes it’s best to compare it to the best possible algorithm. Remarkably, to do so we don’t necessarily need to know what the best possible algorithm is!

5.1. Self-organizing Lists Problem

Self-organizing lists problem: A list 𝐿 contains 𝑛 elements with distinct keys. The list must support the single operation Access(𝑥), which returns the element with key 𝑥. After every access, we may reorder the elements in 𝐿 with transpositions with the goal of making future accesses cheaper.

It turns out the finding the best offline algorithm is NP-hard. For 𝑛 queries, even the best offline algorithm needs Ω(𝑛2) cost. Consider the input 𝐿={1,2,…,𝑛} and the access sequence 𝑛,𝑛−1,𝑛−2,…,1. Partition the array into thirds, and argue each of the last 𝑛3 elements either needs to be moved to one of the first 𝑛/3 slots in Ω(𝑛/3) moves or else its access will cost at least 𝑛/3.

Methods for the online case:

  1. Assuming random queries, we can do an average-case analysis. Suppose key 𝑥is accessed with probability 𝑝(𝑥). THen we should sort 𝐿 in decreasing order of 𝑝(𝑥). Thus a heuristic for the online problem is to try to learn 𝑝(𝑥). But an adversary can still force poor performance.
  2. Move-to-front (MTF): After accessing 𝑥, move 𝑥 to the head so that the total cost is 2rank𝐿(𝑥)−1

Definition 1. Let OPT be the optimal offline algorithm. Let 𝐴 be an online algorithm. Then we say 𝐴 is 𝛼-competitive if there exists constant 𝑐 such that for any access sequence 𝑆,

𝐶𝐴(𝑆)≤𝛼𝐶OPT(𝑆)+𝑐. (11)
Theorem 2. MTF is 4-competitive for self-organized lists.
Proof

After access 𝑖 for 𝑖≥1, let 𝐿𝑖 be MTF’s list and 𝐿𝑖∗ be OPT’s list. The cost of the 𝑖th access plus reordering is

𝑐𝑖=2rank𝐿𝑖−1(𝑥𝑖)−1𝑐𝑖∗=rank𝐿𝑖−1∗(𝑥𝑖)+𝑡𝑖 (12)

where 𝑡𝑖 is the number of transpositions does after access 𝑖.

The idea is to define a nonnegative potential function 𝜑(𝑖) so that

∑𝑖=1|𝑆|𝑐𝑖≤∑𝑖=1|𝑆|𝑐̂𝑖≤4∑𝑖=1|𝑆|𝑐𝑖∗where𝑐̂𝑖=𝑐𝑖+𝜑𝑖−𝜑𝑖−1 (13)

Define 𝜑(𝑖) to be 2 times the number of inversions between 𝐿𝑖 and 𝐿𝑖∗. Clearly 𝜑(0)=0 and 𝜑(𝑖)≥0 for all 𝑖 since the number of inversions is nonnegative so 𝜙 is a valid potential function.

It turns out the minimum number of transpositions needed to transform 𝐿 into 𝐿∗ is precisely the number of inversions between 𝐿 and 𝐿∗. Thus, a transposition changes 𝜙 by at most ±2.

Partition 𝐿𝑖−1=𝐴∪𝐵+{𝑥}+𝐶∪𝐷 and 𝐿(𝑖−1)∗=𝐴∪𝐶+𝑥+𝐵∪𝐷, so that rank𝐿𝑖−1(𝑥)=|𝐴|+|𝐵|+1. From some algebra and inequalities, we show that 𝑐̂MTF≤4𝑐OPT.

□

Remarks:

  1. Our proof did know the exact form or make any assumptions about OPT!
  2. If the cost of a transposition is changed to 2, the competitive changes to 𝛼=6.
