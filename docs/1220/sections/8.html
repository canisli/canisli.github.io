8. Maximum Flow

Given a directed graph 𝐺=(𝑉,𝐸) where each edge (𝑢,𝑣)∈𝐸 has a capacity 𝑐(𝑢,𝑣)≥0, return the greatest possible flow from a designated source node 𝑠 to a designated sink node 𝑡 subject to capacity constraints and flow conservation. By flow conservation, in an allowed configuration all the the flow leaving 𝑠 enters 𝑡.

Define a gross flow function 𝑔:𝑉×𝑉→ℝ. We define 𝑐(𝑢,𝑣)=0 if (𝑢,𝑣)∉𝑒, and 𝑔(𝑢,𝑣)≤𝑐(𝑢,𝑣). Value of the flow is the net flow out of the source: ∑𝑣∈𝑉𝑔(𝑠,𝑣)−∑𝑣∈𝑉𝑔(𝑣,𝑠).

Define the net flow as 𝑓(𝑢,𝑣)=𝑔(𝑢,𝑣)−𝑔(𝑣,𝑢) so that 𝑓 is skew symmetric bilinear form. The value of a flow 𝑓 is |𝑓|=∑𝑣∈𝑉𝑓(𝑠,𝑣)=𝑓(𝑠,𝑉)=𝑓(𝑉,𝑡).

Results:

  • Flow conservation: 𝑓(𝑣,𝑉)=0 for 𝑣∉{𝑠,𝑡}. |𝑓|≡𝑓(𝑠,𝑉)=𝑓(𝑉,𝑡).
  • |𝑓|=𝑓(𝑆,𝑇) for any cut (𝑆,𝑇) where 𝑠∈𝑆,𝑡∈𝑇.
  • The capacity of any flow is bounded above by the capacity of any cut.
  • Define the residual graph 𝐺𝑓 as having edges with residual capacities 𝑐𝑓(𝑢,𝑣)=𝑐(𝑢,𝑣)−𝑓(𝑢,𝑣)>0.
    • An edge (𝑢,𝑣) is in 𝐺𝑓 only if (𝑢,𝑣)∈𝐸 or (𝑣,𝑢)∈𝐸. Hence |𝐸𝑓|≤2|𝐸|.
    • The residual capacities represent how much more net flow we can get from 𝑢 to 𝑣 by tweaking the flows along (𝑢,𝑣) and (𝑣,𝑢). If we do this for a simple path from 𝑠 to 𝑡, then we can increase the total flow while maintaining conservation of flow. This is called an augmenting path.

8.1. Max-flow, min-cut Theorem

Theorem 5 (Max-flow, min-cut). The following are equivalent:
  1. 𝑓 is a max flow on 𝐺.
  2. 𝐺𝑓 contains no augmenting paths.
  3. |𝑓|=𝑐(𝑆,𝑇) for some cut (𝑆,𝑇) of 𝐺
Proof
1→3: Suppose 𝑓 is a max flow on 𝐺. If 𝐺𝑓 contained an augmenting path we could improve |𝑓|. Contradiction.
2→3: Supose 𝐺𝑓 contains no augmenting paths. Let 𝑆 be the set of nodes reachable from 𝑠 in 𝐺𝑓. Then for every edge 𝑐(𝑢,𝑣) from 𝑆 to 𝑇, we must have 𝑐(𝑢,𝑣)=𝑓(𝑢,𝑣) otherwise 𝑣 would be reachable from 𝑠. Hence |𝑓|=𝑓(𝑆,𝑇)=𝑐(𝑆,𝑇).
3→1: For any cut |𝑓|≤𝑐(𝑆,𝑇). Hence |𝑓| is maximized.

□

  • Monotonicity lemma: Breadth first distance 𝛿(𝑣) increases monotonically during EK algorithm. Every time we “kill” an edge and revive it later, the distance must have increased by 2. As a corollary, if the flow network has integer capacities then there exists a max flow 𝑓 with integer flows based on this construction.

The SOTA polynomial time is 𝑂(𝑉𝐸) from Orlin. Chen et al give a pseudopolynomial algorithm when capacities are positive integers.

8.2. Example: Maximum Bipartite matching

Example 1 (Maximum Bipartite matching). There are M job applicants and N jobs. Each applicant has a subset of jobs that he/she is interested in. Each job opening can only accept one applicant and a job applicant can be appointed for only one job. Find an assignment of jobs to applicants in such that as many applicants as possible get jobs.
