11.2. 𝐿2 Geometric picture

Let’s try to motivate this definition and reconcile it with the classical definition of conditional expectation:

𝔼[𝑋|𝐴]=𝔼[𝑋𝟙𝐴]ℙ(𝐴) (76)

The setup is as follows:

  1. Measurable functions wrt σ-fields ℱ︀ of Ω form subspaces of 𝐿2(Ω). Denote 𝐿2(ℱ︀) as these subspaces.
  2. Expectation is an inner product on 𝐿2(Ω).

  3. Conditional expectation is an orthogonal projection. In particular, we define 𝑌=𝔼[𝑋|𝒢︀]∈𝐿2(𝒢︀) as satisfying

    𝔼[(𝑋−𝑌)𝑍]=0for all𝑍∈𝒢︀ (77)

    This is exactly an orthogonality projection: the residual is orthogonal to all functions in the subspace. By the result from L25, this is unique (a.s. / modulo null sets) and it suffices to just check 𝑍=𝟙𝐴 for events 𝐴∈𝒢︀.

Let 𝒢︀={Ø,𝐴,𝐴𝑐,Ω}, so that 𝑌∈𝐿2(𝒢︀) are in the form 𝑌=𝑐1𝟙𝐴+𝑐2𝟙𝐴𝑐. Then the classical conditional expectation (Equation 76) is the value of 𝔼[𝑋|𝒢︀] for 𝜔∈𝐴.

Remark. This isn’t the full story. Conditional expectation still exists for 𝑋∈𝐿1\𝐿2. The 𝐿2 picture is a corollary of the Radon-Nikodym theorem.

ℱ︀𝑡=𝜎(𝜔1,…,𝜔𝑡), (78)
the smallest σ-field that makes each map 𝜔𝑖 measurable, i.e. the generators are events in the form {𝜔:𝜔𝑖=𝐻} or {𝜔:𝜔𝑖=𝑇}. Then {ℱ︀𝑡} is a filtration.

In the above example, 𝜎(𝜔1) is the set of all events that depend only on toss 1. Let 𝐴𝐻={𝜔:𝜔1=𝐻} and 𝐴𝑇={𝜔:𝜔1=𝑇}. Then the σ-field generated must contain Ø,Ω,𝐴𝐻,𝐴𝑇. Since (𝐴𝐻)𝑐=𝐴𝑇, we have

𝜎(𝜔1)={Ø,Ω,𝐴𝐻,𝐴𝑇} (79)

For 𝑡=2, the generators are {𝐴1𝐻,𝐴1𝑇,𝐴2𝐻,𝐴2𝑇}. We can instead use the four cylinder sets 𝐶HH,𝐶HT,𝐶TH,𝐶TT which partition Ω7. The σ-field generated by a partition contains all unions of those sets. For example for 𝑡=2 we have 24 possible events: “first toss = H” is 𝐶HH∪𝐶HT and “both tosses same” = 𝐶HH∪𝐶TT. In general ℱ︀𝑡 has 22𝑡 events. You cannot directly see this from the primitive generators.
